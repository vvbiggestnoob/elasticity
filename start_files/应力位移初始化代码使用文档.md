# 应力位移初始化代码使用文档

> 本文档对应 `start/mech_init.py` 的 PyTorch 实现，规格的唯一权威说明见工作区根目录
> 《应力位移初始化说明.md》，数值取自《实验设置与计算范围.md》。修改实现时文档需同步修订。

## 1. 文件清单

```
start/
├── networks.py          # 网络创建/保存/加载（复用，不修改）
├── sdf_init.py          # 上一步：SDF 初始化（产出 weights/phi_init.pt）
├── mech_init.py         # 本步骤：应力/位移初始化（PINN 特征值训练，两阶段）
└── （运行后生成）
    ├── mech_figures/    # 训练过程图片 + 损失曲线 + 最终结果图
    └── weights/
        ├── phi_init.pt      # （输入）冻结的 SDF 网络
        ├── u_x_init.pt      # （输出）5 个力学网络权重
        ├── u_y_init.pt
        ├── sigma_xx_init.pt
        ├── sigma_xy_init.pt
        └── sigma_yy_init.pt
```

依赖：Python 3 + PyTorch（float64，CPU 可跑）+ matplotlib（仅存图，Agg 后端）。
运行前需已有 `weights/phi_init.pt`（SDF 初始化产物）。

## 2. 实现内容（与《应力位移初始化说明.md》的对应关系）

| 说明文档规格 | 实现 |
|---|---|
| 5 个力学网络，输入 (x,y)，4×64 tanh（`cfg.hidden_layers`），float64 | `build_mechanics_networks()`（复用 `networks.py`） |
| 材料场 S=H(φ)，ρ=S·ρ̂，冻结 SDF | `load_frozen_phi()` + `material_fields()`（requires_grad=False） |
| ρ̂：重块区 100、其余 1 | `block_indicator()`（硬指示函数） |
| E 的取法：**ersatz 插值** E = E_void + (E_solid−E_void)·S | `material_fields()`（设计决策，见 §5） |
| 应变 = u 网络一阶自动微分（物理坐标） | `mech_quantities()` |
| 平面应力本构 σ^u | `constitutive_stress()` |
| (1) 平衡残差 (2) 本构残差 (6) 质量归一化 (7) Rayleigh 商 | `interior_losses()` |
| (3) 重块加密项（重块邻域再算 (1)+(2)） | `block_losses()` |
| (4) Dirichlet（左右）(5) Neumann（上下），掩码统一 S | `dirichlet_loss()` / `neumann_loss()` |
| 7 项加权和，w_dir=w_norm=10，其余 1 | `compute_total_loss()`，`MechInitConfig.w_*` |
| 阶段 A：Sobol 点池 + 每步 minibatch 重采 | `sample_interior_pool()` + `minibatch()` + `train_adam()` |
| 重块邻域加密点池 | `sample_block_pool()`（重块矩形外扩 `block_margin=0.06`） |
| 余弦退火 lr 1e-3→1e-5，4000 步 | `CosineAnnealingLR` |
| Adam 停滞提前切换（默认开）：满 2000 步后 300 步窗口改善 < 5e-3 即切 L-BFGS | `train_adam()` 内，`cfg.adam_early_switch` 等 |
| Rayleigh warmup：前 500 步关闭 L_ray | `train_adam()` 内 `use_ray = step >= cfg.rayleigh_warmup` |
| 阶段 B：L-BFGS 固定点集全批量，强 Wolfe，60 块×70 次 | `train_lbfgs()`（**优化器全程只建一次**，曲率历史跨块累积） |
| 独立验证集监控 | `train_lbfgs()` 内（验证集不同种子，只打印不参与决策） |
| 早停 / 回滚（**默认关闭**，配点即网格、充分拟合为目标） | `cfg.lbfgs_early_stop` / `cfg.lbfgs_rollback`，置 True 恢复说明文档 §6 行为 |
| 诊断：R 对拍、m、PDE 残差 RMS | `diagnose()` |
| 保存 5 个力学网络权重 `*_init.pt` | `main()` 末尾逐网络 `torch.save` |

采样规模全部按《实验设置与计算范围.md》§11：Adam 点池 20000+3000+2000/边、
每步 batch 4096+512+256/边；L-BFGS 固定 8000+800+300/边；验证集 8192+1024+256/边。

## 3. 快速开始

```bash
cd start
python mech_init.py
```

> 路径说明：`weights_dir` / `fig_dir` / `phi_path` 等相对路径一律相对
> `mech_init.py` 脚本所在目录解析（`SCRIPT_DIR`），因此从任意工作目录
> 运行（如工作区根目录 `python start/mech_init.py`）都能正确找到文件。

全程 CPU 可跑（float64 + 双重反向传播，比 SDF 初始化慢，预计小时级）。运行过程：

1. **阶段 A（Adam）**：每步从点池重采 minibatch。每 **100 步**打印一次
   （total / pde / cons / blk / dir / neu / norm / ray / m / R / lr），
   每 **500 步**保存一张六联图到 `mech_figures/`（|u|、u_x、u_y、σ_xx、σ_xy、σ_yy，
   均乘材料场 S，孔洞区域置 0；S 取当前几何切片 t = `phi_t`）。
   前 500 步 `ray` 列显示 `nan`（warmup 关闭中），属正常。
2. **阶段 B（L-BFGS）**：固定点集全批量，优化器全程复用（曲率历史跨块累积），
   每块最多 70 次内部迭代，**按块**打印（train / val / 相对改善），
   每 5 块存一张图（`fig_every_blocks`）。默认**不早停、不回滚**，跑满全部块、
   保留最终权重（val 列仅供参考）；早停开启时可用 `early_stop_metric` 选观察
   `"val"`（防过拟合）或 `"train"`（拟合到收敛才停），规则为观察损失**逐块
   相对下降**连续 `early_stop_patience` 块 < `early_stop_rtol` 即停（交替循环中
   力学重解取 train + rtol 0.1 + 5 块）。
   如需说明文档 §6 的早停+回滚行为，
   置 `lbfgs_early_stop=True, lbfgs_rollback=True`。
3. **收尾**：保存 `loss_history.png`（左 Adam 各项分量、右 L-BFGS train/val）、
   `final.png`（最终场）、5 个 `*_init.pt`，然后打印诊断结果。

自定义配置（如冒烟测试）：

```python
from mech_init import MechInitConfig, main

cfg = MechInitConfig(adam_steps=200, lbfgs_blocks=2,
                     fig_dir="mech_figures_test", weights_dir="weights_test")
main(cfg)
```

## 4. 输出解读

### 4.1 打印日志

- **m 列**（质量积分）应随训练趋向 1；若 m → 0 且各项损失都很小，
  说明场在塌缩（平凡解），检查 L_norm 是否生效。
- **R 列**（Rayleigh 商）warmup 后应逐渐接近锚点 ω²_FEM = 0.2252（实测回填值）。
- L-BFGS 段关注 `val`（独立验证集损失），早停与回滚均以它为准。

### 4.2 诊断（训练末尾自动打印，对应说明文档 §7）

- **Rayleigh 商 R 与 FEM 锚点的相对误差**：核心对拍指标；
- **质量积分 m**：应 ≈ 1；
- **PDE 残差 RMS**（S 加权）与 **Dirichlet / Neumann 边界残差 RMS**；
- 与 FEM 模态的 MAC / 加权 L2 需要 FEM 模态位移数据，当前阶段暂无，
  留待后续对拍（诊断函数中已注明）。

### 4.3 图片

`mech_figures/` 下：`step000000_initial.png`（未训练初始状态）、
`adam_step*.png`（每 500 步）、`lbfgs_block*.png`（每块）、
`loss_history.png`（损失曲线）、`final.png`（最终结果）。
模态图看 `|u|` 面板：基频模态应在重块附近有显著响应。

## 5. 关键设计说明（实现层面的决策记录）

1. **E 取 ersatz 插值**：E = E_void + (E_solid−E_void)·S（E_void=1e-6）。
   初始设计为全材料，内部 S≈1、边界上 S=0.5，E 场几乎处处为 E_solid；
   该插值与后续演化阶段（出现真实孔洞）的约定保持一致。
2. **ω²_FEM = 0.22517705**：原为占位锚点 0.238；2026-09-03 FEM 求解器
   （`start/fem_solver.py`）实测后已回填为 160×50 细网格实测值
   （粗网格 0.19397494，Richardson 外推 0.23557776 供参考）。
   注意：`weights/` 下既有的 5 个力学网络权重是按旧锚点 0.238 训练的，
   以新锚点为准需重跑 `mech_init.py`。
3. **重块邻域定义**：重块矩形 [0.76,0.84]×[0.21,0.29] 四边外扩
   `block_margin=0.06`（即采样盒 [0.70,0.90]×[0.15,0.35]，裁剪到域内），
   盒内均匀采样。说明文档未指定邻域大小，此为实现自定义。
4. **边界 minibatch 的解释**：§11 的"每步 batch 2×256"实现为
   Dirichlet 两条边（左、右）共 512 点、Neumann 两条边（上、下）共 512 点，
   每条边 256 点（`batch_boundary_per_edge`）。
5. **早停与回滚默认关闭**（`lbfgs_early_stop=False, lbfgs_rollback=False`）：
   设计决定是充分拟合固定配点集——配点相当于离散"网格"，train 损失压到底
   正是目标，验证集仅打印观察、不参与决策。开启后行为为：连续
   `early_stop_patience=5` 块验证损失相对改善 < `early_stop_rtol=1e-4` 早停，
   结束回滚到验证最优权重。
6. **验证/诊断不开双重图**：`mech_quantities(create_graph=False)` 只算一阶导
   不建二阶图，验证集评估省内存；训练路径恒为 `create_graph=True`。
7. **材料场不建图**：SDF 冻结，S/ρ/E 在 `torch.no_grad()` 下作为常数权重
   参与损失，不回传梯度到 phi。
8. **L_ray 的 warmup 只作用于 Adam 段**；进入 L-BFGS 后恒开启。
9. **加速设计**（目标 = 充分拟合固定配点集）：
   - L-BFGS 优化器跨块复用，逆 Hessian 近似不清零，同等损失下总迭代数更少；
   - Adam 停滞提前切换（`adam_early_switch`，默认开）：Adam 尾部 lr≈1e-5
     推进很慢，检测到停滞（满 `adam_switch_min_step=2000` 步后、
     `adam_switch_window=300` 步窗口内 total 相对改善 < `adam_switch_rtol=5e-3`）
     即提前进入 L-BFGS；
   - L-BFGS 存图降频（`fig_every_blocks=5`），减少 matplotlib 开销。

## 6. 后续衔接

训练得到的 `u_x_init.pt, u_y_init.pt, sigma_xx_init.pt, sigma_xy_init.pt,
sigma_yy_init.pt` 供后续交替演化阶段加载（与 `phi_init.pt` 一起构成完整的
初始状态）。加载方式与 `networks.py` 的约定一致：

```python
import torch
from networks import NetworkConfig, build_mechanics_networks, MECH_NET_NAMES

mech = build_mechanics_networks(NetworkConfig())
for name in MECH_NET_NAMES:
    mech[name].load_state_dict(torch.load(f"weights/{name}_init.pt", weights_only=True))
```
