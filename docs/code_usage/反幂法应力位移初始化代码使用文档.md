# 反幂法应力位移初始化代码使用文档

> 本文档对应 `start/mech_init_ipm.py` 的 PyTorch 实现（2026-09-11 新建）。
> 方案来源：2026-09-11 审查定稿的《神经网络反幂法应力位移初始化方案》
> （反幂法思想取自 Yang et al., *CAMWA* 2023 的 IPMNN，见根目录《幂反幂.pdf》）。
> 基线对照为《应力位移初始化说明.md》与 `start/mech_init.py`（锚定版，未改动）。
> 修改实现时本文档需同步修订。

---

## 1. 目的与定位

锚定版 `mech_init.py` 的 7 项损失中有 3 项依赖 FEM 特征值 ω²_FEM 或为其补偿而存在：

- (1) 平衡残差 ∇·σ^NN + ω²_FEM·ρ·u^NN —— ω²_FEM 直接进入 PDE 残差；
- (6) 质量归一化 (m−1)² —— 残差对 (u,σ) 齐次，u≡0 是解，需钉振幅；
- (7) Rayleigh 商锚定 (R/ω²_FEM−1)²。

本文件实现**无 FEM 锚定**的力学初始化：

1. ω² 从"输入锚点"变为"输出读出"（Rayleigh 商，训练结束后计算）；
2. 归一化从"损失项"变为"迭代/自洽结构"（无 L_norm）；
3. FEM 只在预拟合提供初始特征函数时用一次（读 `fem_results/fem_result.npz`
   的第 1 阶模态），其余环节（含将来的交替循环）不再需要 FEM。

与 `mech_init.py` 的关系：**复用其基础函数（import），不改动其任何代码**。
复用清单：`load_frozen_phi` / `heaviside_s` / `material_fields` / `block_indicator`
（经 material_fields）/ `sample_interior_pool` / `sample_block_pool` /
`sample_boundary_pools` / `minibatch` / `mech_quantities` / `constitutive_stress` /
`dirichlet_loss` / `neumann_loss` / `save_field_figure` / `_resolve`。
网络结构（4×64 tanh × 5，float64，内置归一化）完全沿用 `networks.py`。

## 2. 两种方法（`cfg.method` 切换）

| method | 残差形式 | 流程 | 状态 |
|---|---|---|---|
| `"selfconsistent"`（默认） | ∇·σ^NN + ρ·u^NN/√m̄ | 单阶段：Adam 固定步 + L-BFGS | 推荐使用 |
| `"ipm_outer"` | ∇·σ^NN + ρ·Ũ_{k-1}（Ũ 冻结） | 外层固定 K 次反幂迭代 | 保留供对照，**已知收敛到虚假不动点**（见 §6.3） |

### 2.1 selfconsistent（自洽特征残差，默认）

把锚定残差中的 ω²_FEM 换成网络自身的 1/√m̄：

$$
\mathbf{r} = \nabla\!\cdot\!\boldsymbol{\sigma}^{NN} + \rho\,\mathbf{u}^{NN}\cdot\frac{1}{\sqrt{\bar m}},
\qquad
\bar m = |\Omega|\cdot\mathrm{mean}_{eval}\bigl(S\hat\rho\,\|\mathbf{u}^{NN}\|^2\bigr)
\ \text{（固定评估集，detach）}
$$

不动点分析：−∇·σ(u) = (1/√m̄)·ρu 与特征方程 −∇·σ(u) = ω²ρu 一致 ⟺ m̄ = 1/ω⁴。
即振幅由方程自身钉在 m = 1/ω⁴（本问题 ≈ 19.7），**无需 L_norm**
（u→0 时 ρu/√m̄ 尺度不变、残差不消失，零解被排除）；
u^NN 直接出现在残差中（与锚定版同构，优化性态经过验证）；
ω² 有两个互为印证的读出：Rayleigh 商 R 与 1/√m̄。

### 2.2 ipm_outer（外层反幂，论文 IPMNN 的严格形式，供对照）

外层固定 K 次迭代，内层把线性系统解到收敛：

$$
\text{给定 } \tilde{\mathbf{U}}_{k-1}\ (m=1):\quad
\text{解 } -\nabla\!\cdot\!\boldsymbol{\sigma}(\mathbf{U}_k) = \rho\tilde{\mathbf{U}}_{k-1},
\qquad
\tilde{\mathbf{U}}_k = \mathbf{U}_k/\sqrt{m(\mathbf{U}_k)},\quad
\omega^2_k = R(\mathbf{U}_k)
$$

Ũ 由一对冻结的 u 网络副本承载（`u_prev`），归一化通过**输出层缩放**实现
（线性输出层缩放 c 倍 = 输出函数精确缩放 c 倍，见 `_scale_output_`）。

**2026-09-11 实测诊断（保留此记录备查）**：该形式在当前混合架构下收敛到
虚假不动点——2 次外层后 R 停在 0.606（FEM 参考 0.225），overlap→0.999，
m 停在 0.6（真解应 ≈19.7），L-BFGS train 0.19 / val 68。原因：u^NN 不在
反幂残差中（残差只含冻结的 Ũ），振幅只能经 L_cons（σ 的零阶匹配）间接获得；
L-BFGS 在固定点集上（8000 点 vs 6.4 万参数）过拟合出"σ 通道单独满足平衡
方程、u 通道滞后"的解。selfconsistent 让 u^NN 直接进残差，正是针对此问题的修复。

## 3. 损失函数（细节）

两种方法均为 **5 项加权和**（掩码统一 S），仅第 (1) 项形式不同：

$$
\mathcal{L} = w_{pde}\mathcal{L}_{eig} + w_{cons}\mathcal{L}_{cons}
+ w_{blk}\mathcal{L}_{blk} + w_{dir}\mathcal{L}_{dir} + w_{neu}\mathcal{L}_{neu}
$$

| 项 | 公式（蒙特卡洛均值，逐点乘 S） | 权重 |
|---|---|---|
| (1) L_eig（内部点） | selfconsistent：$\frac{1}{N_i}\sum_i S_i\,\|\nabla\!\cdot\!\boldsymbol{\sigma}^{NN}_i + \rho_i\mathbf{u}^{NN}_i/\sqrt{\bar m}\|^2$；ipm_outer：$\frac{1}{N_i}\sum_i S_i\,\|\nabla\!\cdot\!\boldsymbol{\sigma}^{NN}_i + \rho_i\tilde{\mathbf{U}}_{k-1}(\mathbf{x}_i)\|^2$ | w_pde = 5 |
| (2) L_cons（内部点） | $\frac{1}{N_i}\sum_i S_i\,\|\boldsymbol{\sigma}^{NN}-\boldsymbol{\sigma}^{u}\|^2$（σ^u 由 u 网络应变经平面应力本构给出，同锚定版） | w_cons = 1 |
| (3) L_blk（重块邻域） | 重块矩形外扩 0.06 的盒内点上重算 (1)+(2) | w_blk = 0.1 |
| (4) L_dir（左右固支） | $\frac{1}{N_D}\sum_d S_d\,\|\mathbf{u}^{NN}\|^2$ | w_dir = 10 |
| (5) L_neu（上下自由） | $\frac{1}{N_N}\sum_n S_n\,[(\sigma_{xy}^{NN})^2+(\sigma_{yy}^{NN})^2]$ | w_neu = 1 |

权重沿用锚定版代码现值（`MechInitConfig.w_pde/w_cons/w_blk/w_dir/w_neu`），
w_pde 复用为 L_eig 的权重。**删除的项**：L_norm（归一化由迭代/自洽结构承担）、
L_ray（ω² 不再是输入）。父类字段 `omega2_fem / w_norm / w_ray /
rayleigh_warmup / adam_early_switch` 在本文件中不使用。

**预拟合损失（阶段 1，两种方法共用）**：

$$
\mathcal{L}_{prefit} = w_{fit}\cdot\underbrace{\frac{1}{N_i}\sum_i
\|\mathbf{u}^{NN}(\mathbf{x}_i) - \Pi\,\mathbf{u}_{FEM}(\mathbf{x}_i)\|^2}_{L_{fit}}
+ w_{cons}\mathcal{L}_{cons} + w_{dir}\mathcal{L}_{dir} + w_{neu}\mathcal{L}_{neu},
\qquad w_{fit}=1
$$

Π 为 FEM 网格双线性插值（`FemMode`，npz 中 `mode1_ux/mode1_uy` 形状
(ny+1, nx+1)，[iy, ix] 对应 (ix·hx, iy·hy)；模态已质量归一化、符号约定为
最大绝对值分量为正）。L_cons 让 σ 网络同步跟上 σ^u，给主训练热启动。

**监控量（不进损失）**：m（批次质量积分）、R（Rayleigh 商，
$\sum S\,\boldsymbol{\sigma}^u\!:\!\boldsymbol{\varepsilon}/\sum S\hat\rho\|\mathbf{u}\|^2$，
与锚定版同口径），selfconsistent 另有 m̄（固定评估集）。

## 4. 训练流程

### 4.1 selfconsistent（默认）

```
阶段 0（一次性，唯一用 FEM）：fem_solver.py 已产出 fem_results/fem_result.npz
阶段 1（预拟合）：Adam 固定 prefit_steps=3000 步，余弦退火 lr 1e-3→1e-5
                 → 选定基频模态盆地（自洽残差的不动点含所有模态，预拟合负责选基频）
阶段 2（主训练）：
    Adam：固定 adam_steps=20000 步（沿用锚定版初始化预算），
          Sobol 点池 + 每步 minibatch 重采（4096+512+256/边），余弦退火；
          每步先在固定评估集（20000 Sobol 点）上重算 m̄（detach）再算损失
    L-BFGS：固定点集（8000+1000+300/边）全批量，强 Wolfe，≤160 块×70 次；
          train 损失逐块相对下降连续 5 块 < 0.02 早停（early_stop_metric="train"）；
          每次闭包重算 m̄（评估集固定 → 损失对参数确定，线搜索一致）
阶段 3（收尾）：全部 5 个网络输出层 × 1/√m_final → m=1 约定；
              保存 *_ipm.pt；诊断；convergence.png；final.png；mech_ipm_result.json
```

### 4.2 ipm_outer（供对照）

```
阶段 1 同上 → normalize_and_update 得 Ũ_0（m=1）
阶段 2：for k = 1..n_outer(=10)：                    # 外层固定次数，无早退
            冻结 Ũ_{k-1}
            Adam 固定 outer_adam_steps=2000 步（minibatch 重采，余弦退火）
            L-BFGS（≤160 块，train 早停 0.02/5；优化器每次外层新建——源项已变，
                   曲率历史不复用）
            Ũ_k ← U_k/√m(U_k)（输出层缩放实现），打印 m、R、overlap
阶段 3 同上（收尾归一化到 m=1）
```

护栏（ipm_outer）：每次外层打印与上一 Ũ 的质量内积重叠（应 →1，<0.9 提示
模态切换风险）；m < 1e-12 视为数值坍缩，中止。

### 4.3 退出条件汇总

| 层级 | 判据 |
|---|---|
| 预拟合 | Adam 固定 3000 步 |
| 主训练 Adam | 固定步数（selfconsistent 20000；ipm_outer 每次外层 2000） |
| 主训练 L-BFGS | train 逐块相对下降连续 5 块 < 0.02 早停；块数 160 兜底 |
| 外层反幂（仅 ipm_outer） | 固定 10 次，无早退；R 只作监控 |

## 5. 快速开始

```bash
cd start
python -u mech_init_ipm.py        # 默认 method="selfconsistent"
```

运行前需已有：`weights/phi_init.pt`（SDF 初始化产物）与
`fem_results/fem_result.npz`（FEM 求解器产物，缺则报错提示先跑 fem_solver.py）。
相对路径一律相对脚本所在目录解析（`_resolve`），从任意工作目录运行均可。
全程 CPU float64，预计小时级（预拟合约 5 分钟 + Adam 约 55 分钟 + L-BFGS 视早停）。

自定义配置（如冒烟测试 / 切换方法）：

```python
from mech_init_ipm import IpmConfig, main

# 冒烟：小参数快速验证流程
cfg = IpmConfig(prefit_steps=200, adam_steps=400, lbfgs_blocks=3,
                lbfgs_max_iter=10, pool_interior=2000, batch_interior=512,
                norm_eval_points=2000, quiet_figures=True,
                save_suffix="_ipm_smoke.pt", fig_dir="mech_figures_ipm_smoke")
main(cfg)

# 对照：外层反幂形式
cfg = IpmConfig(method="ipm_outer", n_outer=10, outer_adam_steps=2000)
main(cfg)
```

主要配置项（`IpmConfig`，继承 `MechInitConfig`）：

| 字段 | 默认 | 含义 |
|---|---|---|
| `method` | `"selfconsistent"` | `"selfconsistent"` 或 `"ipm_outer"` |
| `fem_npz` | `fem_results/fem_result.npz` | FEM 模态数据（预拟合目标 + ω² 对照） |
| `prefit_steps` / `w_fit` | 3000 / 1.0 | 预拟合 Adam 步数 / L_fit 权重 |
| `adam_steps` | 20000（继承） | selfconsistent 主训练 Adam 固定步数 |
| `n_outer` / `outer_adam_steps` | 10 / 2000 | ipm_outer 外层次数 / 每次外层 Adam 步数 |
| `lbfgs_blocks` / `lbfgs_max_iter` | 160 / 70 | L-BFGS 块数上限 / 块内迭代数 |
| `early_stop_metric` / `early_stop_rtol` / `early_stop_patience` | `"train"` / 0.02 / 5 | L-BFGS train 早停 |
| `norm_eval_points` | 20000 | 固定评估集规模（m̄ / 外层归一化 / R 读出） |
| `save_suffix` / `fig_dir` | `"_ipm.pt"` / `"mech_figures_ipm"` | 输出命名（不覆盖锚定版产物） |

## 6. 输出解读

### 6.1 日志列（selfconsistent）

- **m**：预拟合后 ≈1，主训练应大致单调增长到 **≈19.7**（= 1/ω⁴，自洽振幅）。
  若 m 不增或坍缩 → 异常；
- **R**：应收敛到 **0.225 附近**（FEM 参考，仅对照）；
- **L-BFGS 的 train vs val**：应同量级。若 val ≫ train（百倍级），
  说明在过拟合固定点集（ipm_outer 的教训），需检查。

### 6.2 诊断（训练末尾自动打印）

Rayleigh 商 R（读出）与 FEM 参考的相对误差、m（归一化后应 ≈1）、
自洽 PDE 残差 RMS（∇·σ^NN + R·ρ·u^NN，S 加权）、Dirichlet/Neumann 残差 RMS。
另写入 `weights/mech_ipm_result.json`（含 R、FEM 对照、相对误差、诊断字典）。

### 6.3 图片

`mech_figures_ipm/` 下：`convergence.png`（selfconsistent：Adam 各项损失 /
L-BFGS train+val / R 随 Adam 步收敛曲线 + FEM 参考线；ipm_outer：损失按外层
拼接 + R 随外层迭代）、`final.png`（六联场图 ×S）；ipm_outer 另有
`outer{k:02d}.png` 每次外层一张场图。

### 6.4 已知问题记录

- **ipm_outer 虚假不动点**（2026-09-11 实测）：见 §2.2。结论：u^NN 必须直接
  进入特征残差，仅靠 L_cons 间接耦合会被 L-BFGS 点集过拟合利用。
- selfconsistent 的 400 步冒烟中观察到 m 短暂下掉（0.24→0.002，欠训练漂移），
  正式长度运行是否稳定增长待验证；若 m 坍缩，优先考虑加大 `w_cons`、
  延长预拟合、或检查 m̄ 评估集规模。

## 7. 关键设计说明（实现层面的决策记录）

1. **m̄ 用固定评估集而非批次统计**：质量集中在重块（占域面积 0.8%），
   4096 点批次内仅 ~33 个块内点，批次 m̄ 噪声 ~18% 太大；固定 20000 Sobol
   评估集上每步重算（detach），确定性、无批次噪声，且 L-BFGS 线搜索一致。
   评估集的 S·ρ̂ 乘积在 main 中预算一次（`srho_eval`），每步只做 2 次 u 前向。
2. **归一化用输出层缩放实现**（`_scale_output_`）：NormalizedMLP 末层为线性层，
   权重偏置同乘 c ⟺ 输出函数精确乘 c；用于 ipm_outer 的 Ũ 归一化与
   两种方法收尾的 m=1 归一化（u、σ 同步缩放，由方程线性性保持自洽）。
3. **u^NN 直接进入特征残差**（selfconsistent）：与锚定版 L_pde 同构
   （ω²_FEM 换成 1/√m̄），继承其已验证的优化性态，避免 ipm_outer 的
  σ/u 通道解耦。
4. **L-BFGS 优化器**：selfconsistent 全程一个（同锚定版）；ipm_outer 每次外层
   新建（源项 Ũ 已变，曲率历史不复用）。
5. **验证集只观察不决策**：沿用锚定版约定（配点即网格），早停看 train。
6. **材料场不建图**：S/ρ/E 在 no_grad 下作为常数权重，不回传梯度到 phi；
   训练路径一阶导 `create_graph=True`（双重反向传播），评估路径 False。
7. **不改动 mech_init.py**：所有复用均为 import；新文件的损失/训练驱动独立实现，
   锚定版行为不受任何影响。

## 8. 与既有流程的衔接

- 输出 `weights/{u_x,u_y,sigma_xx,sigma_xy,sigma_yy}_ipm.pt`（m=1 约定，
  与 `*_init.pt` 命名区分、互不覆盖），加载方式同 `networks.py` 约定；
- **交替循环接入（尚未实现，方案要点）**：第 k 步力学重解以第 k−1 步收敛解
  为初始（selfconsistent 直接热启动 5 网络；ipm_outer 则 Ũ_0 复用上一步 Ũ），
  `fem_check=False`，`omega2_anchor_from_state` 锚点链退役（力学不再需要
  ω² 输入），HJB 侧本就用 PINN Rayleigh（`rayleigh_and_area`）不受影响；
- `fem_solver.py` 转为纯离线验证工具（初始几何对拍 + 提供预拟合模态）。
