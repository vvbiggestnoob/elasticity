# 交替循环代码使用文档（alternating_loop.py）

## 1. 概述

`alternating_loop.py` 是拓扑优化的外层交替循环驱动脚本，把两个已有的单步模块串成闭环：

```
初始几何 phi_init.pt（sdf_init.py 产物）+ 初始力学 *_init.pt（mech_init.py 产物）
        │
        ▼
第 k 次迭代（k = 1 .. n_iter，t_k = k·dt）：
  Step B  HJB 演化（hjb_step_eik.py）：冻结力学 mech_{k-1}，
          phi 从 phi_{k-1} 热启动，在窗口 [t_{k-1}, t_k] 上解 HJB
          → 输出 phi_iter{k}.pt + hjb_state_iter{k}.json
  Step A  力学重解（mech_init.py）：在新几何 phi_k 的 t = t_k 切片上，
          从 mech_{k-1} 热启动重训 5 个力学网络
          → 输出 *_iter{k}.pt（u_x/u_y/sigma_xx/sigma_xy/sigma_yy）
        │
        ▼
loop_history.json + 汇总图（history.png / zero_level_sets.png）
```

运行方式：

```bash
cd start
python alternating_loop.py            # 用 LoopConfig 默认值
```

或在 Python 中自定义：

```python
from alternating_loop import LoopConfig, main
main(LoopConfig(n_iter=20, dt=0.05, mech_adam_steps=3000))
```

## 2. 运行前提

`weights/` 下必须已存在（脚本启动时检查，缺失会报错并提示）：

- `phi_init.pt` —— 由 `sdf_init.py` 生成；
- `u_x_init.pt, u_y_init.pt, sigma_xx_init.pt, sigma_xy_init.pt, sigma_yy_init.pt` —— 由 `mech_init.py` 生成（其 ω²_FEM 锚点 0.22517705 对应初始全材料几何，见《应力位移初始化说明.md》§13）。

## 3. 变量传递约定（核心，改动前务必理解）

交替循环最容易出错的就是跨模块的变量传递。本脚本固定以下五条约定：

### 3.1 伪时间线程

- 第 k 步 HJB 的时间窗口为 **[t_{k-1}, t_k]**，t_k = k·dt，由 `LoopConfig.dt` 决定；
- `phi_iter{k}.pt` 是在该窗口上训练的**时空**网络 phi(x, y, t)；"第 k 步几何"永远指其**右端切片** t = t_k；
- HJB 步内 `phi_ref` 在 `t_current = t_{k-1}` 切片取值（hjb_step_eik 内部用 `cfg.t_current`，循环按 k 设置）；
- 力学重解通过 `MechInitConfig.phi_t = t_k` 在**同一切片**取材料场（`heaviside_s`）。
- **两处切片必须一致**：力学若错用 t=0（mech_init 的原始硬编码），解的就是初始几何而不是当前几何——这正是本次给 mech_init.py 加 `phi_t` 字段的原因。

### 3.2 权重命名链

| 内容 | k=0（初始） | k≥1 |
|---|---|---|
| SDF | `phi_init.pt` | `phi_iter{k}.pt` |
| 力学（5 个） | `*_init.pt` | `*_iter{k}.pt` |
| HJB 状态 | — | `hjb_state_iter{k}.json` |

每步写新文件、不覆盖上游，任何中间步都可单独复查或从该处重启。力学跳步时用**复制**保持链条连续（见 §4.2）。

### 3.3 ω²_FEM 锚点传递

mech_init 的平衡方程残差 `∇·σ + ω²ρu = 0` 和 Rayleigh 锚定都使用配置中**固定的** `omega2_fem`。几何每演化一步，真实 ω² 就变一次，锚点必须跟着更新，否则力学网络在解一个错误特征值的方程。

传递链：HJB 步诊断（`fem_check=True`）在演化后几何上做 FEM 对拍（160×50 细网格 shift-invert），写入 `hjb_state_iter{k}.json` 的 `omega2_fem_after` → 循环读取该值作为本次力学重解的 `omega2_fem`。

回退顺序（会打印警告）：

```
omega2_fem_after（FEM，首选）
  → omega2_after_rayleigh_frozen_mech（PINN Rayleigh 商，fem_check=False 或 FEM 失败时）
    → 上一步的锚点（都缺失时兜底）
```

### 3.4 热启动链

- **phi**：hjb_step_eik 内部自动完成（phi 与 phi_ref 从同一文件加载，phi 可训练、phi_ref 冻结）；
- **力学**：循环设置 `MechInitConfig.init_suffix = 上一步后缀`，mech_init 加载上一步权重作为初值。几何每步只走一个 dt，力学解变化小，因此重解训练量（默认 Adam 500 + L-BFGS 20 块）远小于初始化（20000 + 160）。

### 3.5 种子

HJB 步 `seed = LoopConfig.seed + k`，力学重解 `seed = LoopConfig.seed + 100000 + k`。每次迭代配点不同，但给定 seed 全程确定可复现。

## 4. 加速机制（利用小 dt 下每步变化小的特性）

### 4.1 预测-校正分裂（HJB 侧）

小 dt 下制造解是真解的 O(dt²) 近似，每步答案在训练前几乎已知。因此把迭代分两种：

- **廉价预测步**：强制 `lam_r = lam_eik = 0`，只用 L_0 + L_anchor 纯回归。锚点损失是逐点 MSE，**不需要自动微分二阶图**，每步成本比完整步低数倍；训练量取 `cheap_adam_steps / cheap_lbfgs_blocks`（默认 500 + 10）。
- **完整校正步**：完整四损失（L_r + L_0 + L_anchor + L_eik），把廉价步累积的一阶截断误差拉回来。每 `full_step_every` 步一次（默认 5），且**第 1 步必为完整步**。

**护栏**：廉价步的诊断仍独立评估真实 HJB 残差（`residual_rms_val`）；若设了 `cheap_residual_tol` 且残差超标，下一步强制完整校正步。默认 None（关闭）——残差量级随配置变，建议先跑几步观察 `hjb_state_iter{k}.json` 里的 `residual_rms_val` 再设。

### 4.2 力学跳步（Step A 侧）

每步 HJB 结束后，循环在 161×51 网格上评估 phi_k 两个端点切片的最大差 max|Δφ| 作为几何变化量度。小于 `mech_skip_tol`（默认 2e-3，参考界面厚度 β=0.01）时跳过重解，把 mech_{k-1} 的 5 个权重文件**复制**为 mech_k（命名链不断），该步 `mech_skipped=True` 记入历史。演化后期几何移动缓慢，大部分步会跳过，整个 Step A 成本归零。ω² 锚点不受跳步影响——FEM 对拍每步照跑，下次真正重解时用最新锚点。置 `mech_skip_tol = 0` 关闭。

### 4.3 停滞检测与早停（循环默认行为）

- **Adam 停滞提前切换**：仅 HJB 步开启（完整步 600/300，廉价步 200/100）；
  **力学重解的 Adam 为固定步数**（`mech_adam_steps`，默认 1250），不做停滞检测。
- **L-BFGS 早停**：均开启且看 **train**（`early_stop_metric="train"`）。
  - 力学重解：train 损失**逐块相对下降连续 5 块 < 0.1** 即退出，
    `mech_lbfgs_blocks` 只是安全上限（默认 30）；
  - HJB 步：train 损失连续 `early_stop_patience` 块无改善且相对改善
    < `early_stop_rtol`（模块默认 1e-4）即停。
  回滚（若开启）始终按 val。

两组开关都由循环在 kwargs 里默认开启，可用 `hjb_extra / mech_extra` 覆盖（如 `hjb_extra={"lbfgs_early_stop": False}`）。

## 5. 配置项（LoopConfig）

| 字段 | 默认 | 说明 |
|---|---|---|
| `n_iter` | 10 | 交替迭代次数，总伪时间 T = n_iter·dt |
| `dt` | 0.05 | 每步伪时间步长 |
| `alpha` | 1.0 | 体积罚参数，当前阶段固定 |
| `v_target` | 0.4 | 面积目标 C = 50% × 0.8 |
| `lam_0 / lam_anchor / lam_eik` | None | HJB 损失权重；**None = 沿用 hjb 模块默认**，避免两处定义漂移 |
| `hjb_adam_steps` | 1500 | 完整校正步 Adam 步数 |
| `hjb_lbfgs_blocks` | 30 | 完整校正步 L-BFGS 块数 |
| `cheap_adam_steps` | 1000 | 廉价预测步 Adam 步数 |
| `cheap_lbfgs_blocks` | 20 | 廉价预测步 L-BFGS 块数 |
| `full_step_every` | 1 | 每 m 步一次完整校正；1 = 关闭预测-校正分裂 |
| `cheap_residual_tol` | None | 廉价步残差护栏；None = 关闭 |
| `mech_skip_tol` | 0 | 力学跳步阈值（max\|Δφ\|）；0 = 不跳过 |
| `mech_adam_steps` | 1250 | 力学重解 Adam 步数（热启动，固定步数不停滞检测） |
| `mech_lbfgs_blocks` | 30 | 力学重解 L-BFGS 块数（安全上限，实际由早停规则决定） |
| `fem_check` | True | 每个新几何的 FEM ω² 对拍；同时是力学锚点来源，**建议保持开启** |
| `hjb_extra / mech_extra` | None | 逃生舱：dict 透传覆盖子模块任意配置字段（不认识的字段自动忽略并提示） |
| `weights_dir` | weights | 权重目录 |
| `loop_fig_dir` | loop_figures | 图片目录 |
| `history_out` | weights/loop_history.json | 历史记录 |
| `seed` | 20260909 | 随机种子基准 |

## 6. 输出文件

```
weights/
  phi_iter{k}.pt              第 k 步 SDF（时空网络，窗口 [t_{k-1}, t_k]）
  u_x_iter{k}.pt 等 5 个       第 k 步力学网络（对应几何 phi_k @ t_k；跳步时为复制的上一接权重）
  hjb_state_iter{k}.json      第 k 步 HJB 诊断（含 omega2_fem_after、residual_rms_val）
  loop_history.json           循环历史（每步落盘，崩溃不丢）
loop_figures/
  history.png                 收敛曲线：F、ω²、面积 vs 迭代步（每步重绘）
  zero_level_sets.png         零水平集叠加图（蓝=初始 → 红=最新，每步重绘）
  iter{k:03d}_hjb/            该步 HJB 的 vn_field.png / final.png / loss_history.png
  iter{k:03d}_mech/           该步力学的 final.png / loss_history.png（跳步时无此目录）
```

`loop_history.json` 每步记录：`cheap`（是否廉价步）、`max_dphi`、`mech_skipped`、F 前后值、面积前后值、ω²（Rayleigh 前/后 + FEM）、HJB 残差 RMS、零水平集 |∇φ| 统计、力学重解的 R/m/残差、各阶段耗时、所用 ω² 锚点。

## 7. 图片策略

子模块以 `quiet_figures=True` 运行：跳过 Adam/L-BFGS 过程图、初始快照、力学场图，每步只留 3+2 张。循环级只维护两张汇总图（每次迭代重绘覆盖同名文件）。需要某步的完整过程图时，用对应配置单独跑一遍该步即可。

## 8. 对既有文件的增量改动清单

为支持交替循环与加速机制，对两个既有模块做了**纯增量**修改（所有新字段默认值保持单独运行行为完全不变）：

**mech_init.py**
- 新增 `phi_t: float = 0.0`：SDF 求值的伪时间切片（`heaviside_s` 原来硬编码 t=0）；
- 新增 `init_suffix: Optional[str] = None`：非 None 时从 `weights_dir/*<init_suffix>` 热启动力学网络；
- 新增 `quiet_figures: bool = False`：精简存图开关；
- `main()` 现在返回诊断字典（原返回 None，不影响旧调用）。

**hjb_step_eik.py**
- 新增 `quiet_figures: bool = False`：精简存图开关；
- 新增 `adam_early_switch / adam_switch_min_step / adam_switch_window / adam_switch_rtol`：Adam 停滞提前切换（逻辑同 mech_init.py，模块默认关闭，循环中开启）；
- `compute_total_loss` 在 `lam_r = lam_eik = 0` 时跳过残差/梯度自动微分（廉价预测步的纯回归模式）；Adam 日志的 r 分量改为按需显示。

**hjb_step.py 未改动。**

## 9. 常见问题

**Q：想换回无 eikonal 的 HJB 版本？**
把 alternating_loop.py 中 `import hjb_step_eik as hjb_mod` 改为 `import hjb_step as hjb_mod`。`lam_eik`、`quiet_figures`、`adam_early_switch` 等不识别字段会被 `_filter_kwargs` 自动忽略（打印提示）——但注意旧版没有精简存图、廉价模式与停滞检测，循环会慢很多且产生大量过程图。

**Q：FEM 对拍失败/太慢？**
`fem_check=False` 关闭，锚点自动回退为 PINN Rayleigh 商（精度略差，见 hjb_state 里的 `fem_vs_rayleigh_rel` 历史偏差）。不建议长期关闭：锚点错了力学就解错了方程。

**Q：廉价步会不会把解带偏？**
单步看，廉价步就是制造解的一阶剖面（O(dt²) 误差）；护栏（`cheap_residual_tol`）和周期完整步（`full_step_every`）负责把累积误差拉回来。观察指标：`loop_history.json` 里廉价步的 `hjb_residual_rms_val` 与完整步的差距，以及 F 轨迹是否在廉价步上持续漂移。

**Q：力学跳步的阈值怎么定？**
看每步打印的 max|Δφ|：界面厚度尺度是 β=0.01，max|Δφ| 长期远小于它说明几何基本不动，跳步安全；若跳步后下一步 HJB 的 V_n 场明显失真（vn_field.png），说明阈值偏大，调小 `mech_skip_tol`。

**Q：中断了怎么续跑？**
当前未实现断点续跑。权重命名链本身支持手动续跑：把 `phi_init_name`/`mech_init_suffix` 指到中断步的文件（如 `phi_iter5.pt` / `_iter5.pt`），并注意 t 从 0 重新计（如需保持绝对伪时间，需自行调整——后续版本可加 `k_start` 参数）。

**Q：每步 F 应该下降吗？**
单步内 V_n 取最速下降方向，F_after < F_before 是预期（hjb 诊断会打印）；跨步的 F_before 序列（即各步起点的 F）整体应趋势性下降并伴随面积向 C 收敛。若持续上升，先查 hjb_state_iter{k}.json 里的残差 RMS 与 |∇φ| 统计。

## 10. 冒烟测试

`_smoke_loop.py`：极小点集与训练步数，只验证链路连通与变量传递，数值无物理意义。分两轮：

- **Run A**：1 次完整迭代（不跳力学），验证命名链、伪时间、锚点回退（fem_check=False 路径）、热启动；
- **Run B**：3 次迭代，`full_step_every=100 + cheap_residual_tol=0 + mech_skip_tol=1`，验证廉价预测步、护栏（k=2 廉价 → k=3 强制完整）、力学跳步复制链。

产物在 `weights_loop_smoke/` 与 `loop_figures_smoke/`，确认无误后可删除。
