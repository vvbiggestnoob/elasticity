# 网络初始化代码使用文档

> 本文档对应 `start/` 目录下的 PyTorch 实现，规格的唯一权威说明见工作区根目录
> 《网络初始化说明.md》。修改网络结构时两份文档需同步修订。

---

## 1. 文件清单

```
start/
├── networks.py          # 核心实现：6 个网络（5 力学 + 1 SDF）的创建、保存、加载
├── verify_networks.py   # 自检脚本：逐条验证《网络初始化说明.md》的规格
└── example_usage.py     # 最小使用示例：前向传播、自动微分、保存权重
```

依赖：Python 3 + PyTorch（已在 torch 2.4.1+cpu 上验证）。无其他第三方依赖。

## 2. 实现内容（与说明文档的对应关系）

| 说明文档规格 | 实现 |
|---|---|
| 5 个力学网络 u_x, u_y, σ_xx, σ_xy, σ_yy，输入 (x, y) | `build_mechanics_networks()` 返回 `nn.ModuleDict` |
| 1 个 SDF 网络 phi，输入 (x, y, t) | `build_sdf_network()` |
| 3 层 × 64 神经元隐藏层，tanh 激活，线性输出 | `NormalizedMLP`（`nn.Sequential`：Linear→Tanh ×3 → Linear） |
| Xavier 正态初始化，偏置置 0 | `NormalizedMLP.reset_parameters()` |
| 内置固定仿射归一化 x̃=2x/Lx−1, ỹ=2y/Ly−1 | 前向第一行的 `(x - shift) * scale`，`shift`/`scale` 为固定 buffer |
| SDF 的 t 通道不归一化 | phi 网络第 3 通道 `shift=0, scale=1` |
| 全程 float64 | `NetworkConfig.dtype = torch.float64`，创建时在 float64 下初始化 |

参数量实测：力学网络 **8577** 个（~8.5K），SDF 网络 **8641** 个（~8.6K），与说明文档一致。

## 3. 快速开始

### 3.1 运行自检（建议先跑）

```bash
cd start
python verify_networks.py
```

输出 9 项检查（网络数量、参数量、float64、归一化角点、t 通道、Xavier 初始化、
输出形状、自动微分 vs 中心差分、保存/加载往返），全部 PASS 且退出码为 0 即正常。

### 3.2 运行示例

```bash
python example_usage.py
```

演示创建网络、前向传播、对物理坐标求一阶导、保存权重到 `weights/`。

### 3.3 在自己的代码中使用

```python
import torch
from networks import NetworkConfig, build_all_networks, save_networks, load_networks

# 创建全部 6 个网络（默认 Lx=1.6, Ly=0.5，float64）
cfg = NetworkConfig()                      # 可改 lx / ly / hidden_layers / hidden_width
bundle = build_all_networks(cfg)
mech, phi = bundle.mechanics, bundle.phi   # mech 是 ModuleDict，按键名取网络

# 前向传播：对外接口始终是物理坐标，归一化在网络内部完成
xy = torch.rand(100, 2, dtype=torch.float64) * torch.tensor([cfg.lx, cfg.ly])
u_x      = mech["u_x"](xy)        # (N, 1)
sigma_xx = mech["sigma_xx"](xy)   # (N, 1)

# SDF 网络输入为 (x, y, t)，初始化阶段 t 恒取 0
xyt = torch.cat([xy, torch.zeros(len(xy), 1, dtype=torch.float64)], dim=1)
phi_val = phi(xyt)                # (N, 1)

# 一阶自动微分：链式法则自动穿过内置固定仿射，
# 得到的是对【物理坐标】的导数，损失公式无需改写
xy_g = xy.clone().requires_grad_(True)
u = mech["u_x"](xy_g)
(du,) = torch.autograd.grad(u.sum(), xy_g)
eps_xx = du[:, 0]                 # ∂u_x/∂x（物理坐标）

# 保存 / 加载（每个网络一个文件：u_x_init.pt ... phi_init.pt，
# state_dict 内含归一化 buffer，加载时无需再传几何参数）
save_networks(bundle, out_dir="weights")
bundle2 = load_networks("weights")
```

## 4. API 一览（networks.py）

| 名称 | 说明 |
|---|---|
| `NetworkConfig` | 配置：`lx=1.6, ly=0.5, hidden_layers=3, hidden_width=64, dtype=float64, save_suffix="_init.pt"` |
| `NormalizedMLP` | 内置固定归一化的 MLP。`forward(x)`：`(N, in_dim)` 物理坐标 → `(N, 1)` |
| `build_mechanics_networks(cfg)` | 创建 5 个力学网络，返回 `nn.ModuleDict`，键为 `MECH_NET_NAMES` |
| `build_sdf_network(cfg)` | 创建 SDF 网络 phi（输入 3 维，t 通道不归一化） |
| `build_all_networks(cfg)` | 一次创建全部 6 个，返回 `NetworkBundle`（`.mechanics` / `.phi` / `.config`） |
| `count_parameters(net)` | 可训练参数总数 |
| `save_networks(bundle, out_dir)` | 按名字分别保存为 `<name>_init.pt`，返回文件路径列表 |
| `load_networks(out_dir, cfg)` | 从目录加载全部 6 个网络，返回 `NetworkBundle` |
| `MECH_NET_NAMES` | `["u_x", "u_y", "sigma_xx", "sigma_xy", "sigma_yy"]` |
| `SDF_NET_NAME` | `"phi"` |

## 5. 关键设计说明

1. **归一化不可训练且随权重保存**：`shift`/`scale` 注册为 `persistent=True` 的
   buffer，不参与训练（不在 `parameters()` 中），但随 `state_dict` 保存，
   保证加载权重时归一化定义与训练时严格一致。

2. **自动微分得到物理坐标导数**：归一化是固定仿射 x̃ = (x − c)·s，链式法则给出
   ∂y/∂x = s·∂y/∂x̃，由 PyTorch 自动完成。自检中已与中心差分对比，
   float64 下误差 ~2e-11。

3. **初始化在 float64 下进行**：创建网络时临时切换 torch 默认 dtype，
   Xavier 采样直接在双精度完成，避免 float32 初始化再转换的精度损失。

4. **已知特性（非 bug）**：由于偏置全零、tanh 为奇函数，域中心点
   (Lx/2, Ly/2) 归一化后为 (0, 0)，所有网络在该点输出恰为 0。训练开始后
   偏置更新，该对称性即消失。
