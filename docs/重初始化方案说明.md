# 重初始化方案说明

> **文档维护**：本文档是 SDF 重初始化（拓扑优化主循环 Step C）的唯一权威说明。实现代码必须与本文档保持一致；
> **实现完成后需要保存并更新本文档**，后续任何对重初始化方程、损失与触发策略的修改都要同步修订本文档。

---

## 1. 目标

在 HJB 演化过程中周期性把 SDF 网络拉回符号距离函数性质（|∇φ| ≈ 1），同时**保持零水平集位置不动**。

HJB 方程只保证零水平集按正确速度运动，不保证 φ 保持距离函数性质。演化多步后 |∇φ| 偏离 1（界面附近变陡或变平），会引发两个问题：

- Heaviside 敏感带很窄（|φ| ≲ 4β ≈ 0.04，β = 0.01），φ 的梯度失真直接造成材料判定 S = H(φ) 失真；
- V_n 经 |∇φ| 项回灌进 HJB 方程，梯度失真累积成演化漂移。

重初始化与 HJB 的分工：**HJB 负责"移动边界"，重初始化负责"维护 SDF 的良好性质"**，二者交替保证拓扑优化长期稳定。

## 2. 重初始化方程

以重初始化前的当前 SDF 为锚点 φ₀（detach，不参与训练），求解

$$
\frac{\partial \phi}{\partial \tau} = \mathrm{sign}(\phi_0)\,\big(1 - |\nabla \phi|\big)
$$

τ 为重初始化伪时间（与 HJB 的演化伪时间 t 无关）。该方程的稳态解满足 |∇φ| = 1；sign(φ₀) 保证各点朝恢复距离函数的方向演化且不改变符号分布，即零水平集不动。

> 论文一的对应形式为 ∂N/∂θ·∂θ/∂t = sign(φ_initial)(|∇N| − 1)，用 Moore-Penrose 伪逆 → ODE → RKF45 求解；本方案改为 PINN 损失 + Adam（§3-4）。

## 3. 损失函数（2 项加权和，不乘掩码 S）

所有积分为采样点蒙特卡洛均值。

**(1) Eikonal 约束**（全域强制梯度模长为 1）：

$$
\mathcal{L}_{eik} = \frac{1}{N_r}\sum_{i=1}^{N_r} \left| \,|\nabla \tilde\phi(x_i, y_i)| - 1\,\right|^2
$$

**(2) 位置保持**（锚定重初始化前的 SDF 值，保护界面位置）：

$$
\mathcal{L}_{pos} = \frac{1}{N_0}\sum_{i=1}^{N_0} \left| \tilde\phi(x_i, y_i) - \phi_0(x_i, y_i) \right|^2
$$

**总损失**：

$$
\mathcal{L}_{reinit} = \lambda_{eik}\mathcal{L}_{eik} + \lambda_{pos}\mathcal{L}_{pos}
$$

| 权重 | 数值 | 说明 |
|------|------|------|
| λ_eik | 1 | |
| λ_pos | 10 | 位置保持权重更大：修梯度，不动界面 |

> **关键：重初始化损失不乘 S。** SDF 性质需要在整个设计域（包括孔洞内部）保持。

## 4. 采样策略

- **Eikonal 点**：全域均匀（或 Sobol 低差异）采样；
- **位置保持点**：在当前零水平集附近（|φ₀| < 0.1）密集采样——界面位置正是必须保护的对象；
- 采样规模（暂定，见 §8）：N_r = 2000，N_0 = 1000。

## 5. 训练流程与触发频率

两阶段训练（与《HJB方程优化说明》§8 同策略）：

**阶段 A：Adam**
- Sobol 低差异点池 + 每步 minibatch 重采；
- 余弦退火 lr：1e-4 → 1e-6，**起点故意小于 HJB 的 1e-3**，避免重初始化本身引起剧烈变化；
- 训练 50~100 步，不要过度训练——过度拟合 Eikonal 反而会挪动界面。

**阶段 B：L-BFGS 精调**
- 固定点集（保证损失确定性）全批量，强 Wolfe 线搜索；
- 分块执行，独立验证集只打印观察；早停与回滚默认关闭，可配置开启；
- L-BFGS 优化器跨块复用（曲率历史累积）。

| 参数 | 数值 | 说明 |
|------|------|------|
| 优化器 | Adam → L-BFGS | 两阶段 |
| Adam 学习率 | 1e-4 → 1e-6（余弦退火） | 小于 HJB 的 1e-3 起点 |
| Adam 训练步数 | 50~100 步 | 不要过度训练 |
| 触发频率 | 每 5~10 步 HJB 执行一次 | 减少累积漂移 |

执行位置：嵌在 HJB 演化循环内（`if hjb_step % reinit_freq == 0`）。先把当前 φ detach 存为锚点 φ₀，再训练 SDF 网络最小化 L_reinit，完成后继续 HJB 演化。

> **当前阶段说明**：单次 SDF 优化只推进一个 dt = 0.005（见《HJB方程优化说明》§2），默认不触发重初始化；本文档流程在多步推进 / 外层迭代阶段启用。

## 6. 终止条件

满足其一即停：

1. 零水平集附近监测 Eikonal 残差 < 1e-2；
2. 达到最大步数（100 步）。

## 7. 诊断（每次执行自检）

- 重初始化前后零水平集位置的漂移量（应 ≈ 0，位置保持是否生效）；
- 全域 |∇φ| 的均值/方差（应向 1 收敛）；
- L_eik 与 L_pos 的下降曲线（防止过度训练）。

## 8. 输出 / 保存

- 重初始化后的 SDF 网络权重覆盖当前状态，供后续 HJB 步继续使用；
- 记录每次重初始化的 Eikonal 残差与界面漂移量，供事后分析。

## 9. 实现记录（设计决策）

- **求解路线**：PINN 损失 + Adam → L-BFGS 两阶段（§5），不采用论文一的伪逆 → ODE → RKF45 路线。
- **网络结构**：SDF 网络 3×64 tanh（输入 (x, y, t)，坐标内置归一化到 [-1,1]²，float64），与《SDF初始化说明》一致；重初始化只更新权重，不改结构。
- **采样与训练超参数**（N_r/N_0、50~100 步、lr=1e-4、每 5~10 步触发）：暂取自《方案_详细版》，《实验设置与计算范围》尚未覆盖演化阶段；实现定稿后应回填《实验设置与计算范围》并同步本文档。
- **锚点处理**：φ₀ 必须 detach，位置保持损失只对当前 SDF 网络起作用，避免梯度回传到演化历史。
