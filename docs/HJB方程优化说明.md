# HJB方程优化说明

> **文档维护**：本文档是 HJB 方程驱动 SDF 演化（拓扑优化主循环 Step B/D）的唯一权威说明。实现代码必须与本文档保持一致；
> **实现完成后需要保存并更新本文档**，后续任何对 HJB 演化、灵敏度与罚参数更新的修改都要同步修订本文档。

---

## 1. 目标

用当前力学解（位移 u、应变 ε、特征值 ω²）构造法向速度 V_n，通过求解 Hamilton-Jacobi 方程

$$
\frac{\partial \phi}{\partial t} + V_n\,|\nabla \phi| = 0
$$

更新 SDF 网络，使材料边界沿目标函数的最速下降方向运动，在面积约束下最大化最小弹性特征值 ω₁²。

优化目标：

$$
\min\; F = -\omega^2 + \frac{1}{2\alpha}\left(\int_\Omega S\,dx - C\right)^2
$$

其中 C = V_target = 0.4（体积分数 50%，域面积 0.8），α 为自适应罚参数（§6，当前阶段固定）。

## 2. 当前计算范围（单次 SDF 优化，先不迭代）

**当前阶段只做一次 SDF 优化，不进入外层交替迭代。** 具体约定：

- **冻结力学网络**：加载初始化阶段保存的 5 个力学网络权重（`u_x_init.pt` 等），本阶段不训练力学网络；
- **V_n 场算一次后固定**：在当前几何（初始为全材料）上由力学网络计算 u、σ、ε、ω² 一次，构造 V_n 场并在本次演化中保持不变；
- **执行一次 HJB 演化**：训练 SDF 网络拟合 t ∈ [t_current, t_current + dt] 上的 HJB 解，推进一个 dt = 0.005；
- **罚参数固定**：α = 1.0（初值），不执行 Step D 的自适应更新；
- **重初始化**：本次只推进单个 dt，默认不触发；若改为多步推进，按《重初始化方案说明》的频率执行；
- 外层循环收敛判据（§8）本阶段不适用，仅作后续迭代阶段的预留。

## 3. 物理问题与符号约定

- 计算域：Ω = [0, Lx] × [0, Ly]，Lx = 1.6（水平），Ly = 0.5（竖直），面积 0.8；无量纲，全程 float64。
- 材料场：S = H(φ)，ρ = S·ρ̂，E = E_void + (E_solid − E_void)·S（ersatz 插值，E_void = 1e-6，E_solid = 1.0，ν = 0.3，平面应力）。
- Heaviside：S = ½(1 + tanh(φ/2β))，β = 0.01；敏感带 |φ| ≲ 4β ≈ 0.04。
- 重块（不可优化）：x ∈ [0.76, 0.84]，y ∈ [0.21, 0.29]，中心 (0.80, 0.25)，ρ̂ = 100；基体 ρ̂ = 1。
- SDF 网络：N_φ(x, y, t)，3×64 tanh，输入含伪时间 t；输入坐标内置归一化到 [-1,1]²。
- 力学量来源：5 个力学网络（4×64 tanh，本阶段冻结）提供 u、σ；应变由 u 网络一阶自动微分得到；ω² 由 Rayleigh 商给出，FEM（160×50 Q4 细网格，shift-invert 取最小特征值）提供锚点。

## 4. 从边界运动到 HJB 方程（推导）

材料边界由零水平集 φ = 0 隐式表示。设边界点 x(t) 随伪时间 t 运动且始终在边界上：

$$
\phi(\mathbf{x}(t), t) = 0
\;\Longrightarrow\;
\frac{\partial \phi}{\partial t} + \nabla\phi \cdot \frac{d\mathbf{x}}{dt} = 0
$$

边界点沿法向运动，dx/dt = V_n·n = V_n·∇φ/|∇φ|，代入得：

$$
\frac{\partial \phi}{\partial t} + V_n\,|\nabla\phi| = 0
$$

> **注意**：方程中是 |∇φ| 而不是 |∇φ|²，因为 n·∇φ = ∇φ/|∇φ|·∇φ = |∇φ|。
> V_n > 0 边界外扩（加材料），V_n < 0 边界内缩（去材料）。

> **符号勘误（2026-09-08 实现时确认）**：在"φ > 0 = 材料"的约定下，∇φ 在边界处
> 指向材料内部，上式中 V_n > 0 实际使边界向材料内部运动（收缩），与 §5 的
> 物理描述及最速下降推导（dF = −∫G² < 0）矛盾。参考论文（DNN Level Set TO，
> 式 (5)）的方程为 ∂Φ/∂t − V_n|∇Φ| = 0，与 §5 自洽。实现采用
> **∂φ/∂t = V_n·|∇φ|**（即残差 r = φ_t − V_n·|∇φ|），V_n 仍按 §5 公式计算，
> V_n > 0 → 边界外扩。详见 §11 实现记录。

## 5. 法向速度 V_n（形状导数 → 最速下降）

对目标函数做形状灵敏度分析（Hadamard 公式），得形状梯度密度

$$
G = -\big(\boldsymbol{\varepsilon}\!:\!\mathbb{A}\!:\!\boldsymbol{\varepsilon} - \omega^2\rho\,\|\mathbf{u}\|^2\big) + \frac{1}{\alpha}\left(\int_\Omega S\,dx - C\right)
$$

取负梯度方向 V_n = −G，保证 dF = −∫G² dS < 0：

$$
V_n = \underbrace{\boldsymbol{\varepsilon}\!:\!\mathbb{A}\!:\!\boldsymbol{\varepsilon}}_{\text{应变能密度}} \;-\; \omega^2\underbrace{\rho\,\|\mathbf{u}\|^2}_{\text{动能密度}} \;-\; \frac{1}{\alpha}\left(\int_\Omega S\,dx - C\right)
$$

物理含义：

- 应变能密度大 → 材料对刚度贡献大 → V_n > 0 → 边界外扩（保留/增加材料）；
- 动能密度大 → 材料只增质量、拉低特征值 → V_n < 0 → 边界收缩（去除材料）；
- 当前面积超过 C 时罚项为负贡献 → 整体收缩，反之放松。

V_n 在当前几何的**全域**上定义（孔洞区内前两项因 E≈0、ρ≈0 自然消失，只剩罚项），由力学网络输出经自动微分在采样点上逐点计算。本阶段 V_n 场计算一次后固定（§2）。

## 6. 罚参数自适应更新（Step D，当前阶段不执行）

每个外层迭代结束后更新：

$$
\frac{1}{\alpha^{(k+1)}} = \min\left(\frac{\omega^2\,\tau}{\left(\int_\Omega S\,dx - C\right)^2},\; \alpha_{max}\right)
$$

| 参数 | 数值 | 说明 |
|------|------|------|
| τ | 1.1 | 缩放因子 |
| α_max | 1e6 | 罚参数上限 |
| α 初值 | 1.0 | **当前阶段固定取此值** |

- 面积偏差大 → 1/α 受 α_max 限制 → 罚项强 → 优先满足面积约束；
- 面积接近目标 → 1/α 由 ω²τ/(ΔV)² 控制 → 罚项适中 → 重心转向特征值优化。

## 7. 损失函数（加权和，不乘掩码 S）

SDF 网络 φ̃ = N_φ(x, y, t; θ)。所有积分为采样点蒙特卡洛均值。

**(1) HJB 残差**（内部点）：

$$
\mathcal{L}_{r} = \frac{1}{N_r}\sum_{i=1}^{N_r} \left| \frac{\partial \tilde\phi}{\partial t}(x_i, y_i, t) - V_n(x_i, y_i)\,|\nabla \tilde\phi(x_i, y_i, t)| \right|^2
$$

∂φ̃/∂t 与 |∇φ̃| 均由自动微分计算。（残差为 φ_t − V_n|∇φ|，符号依据 §4 的勘误；
2026-09-08 前本文档此处为 "+" 号，与 §5 的 V_n 物理方向矛盾。）

**(2) 初始条件**（t = t_current 切片锚定当前 SDF；含边界带加密点）：

$$
\mathcal{L}_{0} = \frac{\sum_{j=1}^{N_0} w_j \left| \tilde\phi(x_j, y_j, t_{current}) - \phi_{current}(x_j, y_j) \right|^2}{\sum_{j=1}^{N_0} w_j}
$$

其中内部 Sobol 点 w_j = 1，**边界带点** w_j = w_ic = 10（带宽 4β、隔点严格压边，
与《SDF初始化说明》的边界带同策略）。边界带锚定 rim 处的 φ——纯内部点采样下
光滑网络会把边界拐角抹圆，rim 处 φ 系统性虚增（见 §11 的 2026-09-08 记录）。

**(3) 制造解锚点**（2026-09-08 新增，可选，λ_anchor 默认 1）：

$$
\mathcal{L}_{anchor} = \frac{1}{N_r}\sum_{i=1}^{N_r} \left| \tilde\phi(x_i, y_i, t_i) - \Bigl[\phi_{current}(x_i, y_i) + (t_i - t_{current})\,V_n(x_i, y_i)\,|\nabla\phi_{current}(x_i, y_i)|\Bigr] \right|^2
$$

HJB 残差只约束比值 φ_t/|∇φ| = V_n——**常函数是残差为零的退化解**，单靠初始
条件无法把剖面钉在整个时间柱面上（实测 rim 处 φ 漂移 +0.03~+0.08，面积失真）。
制造解（一阶 Taylor）给出显式剖面目标，破除退化；置 λ_anchor = 0 退回纯 PINN。

**总损失**：

$$
\mathcal{L}_{HJB} = \lambda_r \mathcal{L}_r + \lambda_0 \mathcal{L}_0 + \lambda_{anchor} \mathcal{L}_{anchor}
$$

参考权重：λ_r = λ_0 = λ_anchor = 1。

> **关键：HJB 损失不乘 S（不过滤孔洞）。** SDF 必须在整个设计域上演化——若过滤孔洞区域，孔洞内 SDF 不更新，就无法生成新孔洞或扩大现有孔洞。V_n 在孔洞内自然退化为罚项，无需额外处理。

> **2026-09-08：移除外边界损失 L_b。** 原文档此处有第 (3) 项"外边界零法向梯度
> L_b"（防止 SDF 在边界处剧烈变化）。参考论文（DNN Level Set TO）对 SDF 不施加
> 域边界条件；且 L_b 与 L_0 在 t=0 棱线上冲突（初始 SDF 在边界上 |∂φ/∂n| = 1），
> PDE 层面还会把边界值钉死、使零水平集永远无法从域边界后退。移除后边界值由
> PDE + 内部信息自然决定（出流式），边界可自由后退。网格对照版（hjb_fem.py）
> 的边界 stencil 同步改为内部单侧差分。

## 8. 训练流程（两阶段：Adam → L-BFGS）

与力学初始化一致的两阶段策略（见《应力位移初始化说明》§6）。

**阶段 A：Adam**
- Sobol 低差异点池 + 每步 minibatch 重采（内部点、初始条件点分别建池；初始条件点含边界带加密）；
- 余弦退火 lr：1e-3 → 1e-5；
- 采样规模（暂定，见 §11）：内部点 N_r = 2000，初始条件点 N_0 = 1000（从内部+边界带合并池抽取）；
- Adam 步数暂定 100~500（单次演化残差简单，宜少不宜多；定稿后回填）。

**阶段 B：L-BFGS 精调**
- 固定点集（保证损失确定性）全批量，强 Wolfe 线搜索；
- 分块执行，用**独立验证集**监控是否过拟合配点；
- 早停与回滚默认关闭（充分拟合固定配点集为目标，验证集只打印观察），可通过配置开启；
- L-BFGS 优化器跨块复用（曲率历史累积）。

**外层循环收敛判据**（后续迭代阶段用，当前阶段不适用；满足其一即停）：
1. 目标函数相对变化 |F⁽ᵏ⁺¹⁾ − F⁽ᵏ⁾| / |F⁽ᵏ⁾| < 1e-4；
2. SDF 变化 ‖φ⁽ᵏ⁺¹⁾ − φ⁽ᵏ⁾‖_∞ < 1e-3；
3. 外层迭代数 k > 200。

## 9. 诊断（训练后自检）

- HJB 残差的 RMS（训练集与独立验证集）；
- 演化前后目标函数 F 与 ω² 的变化（V_n 取最速下降方向，F 应下降）；
- 演化前后面积 ∫S dx 与目标 C = 0.4 的偏差；
- 零水平集位置对比图（演化前 vs 演化后）；
- 零水平集附近 |∇φ| 的分布（偏离 1 的程度，评估是否需要重初始化）；
- 与 FEM 对拍：演化后几何下的 ω²_FEM 与 PINN Rayleigh 商。

## 11. 实现记录（设计决策）

- **几何方向**：以《实验设置与计算范围》为准——Lx = 1.6 水平、Ly = 0.5 竖直，重块中心 (0.80, 0.25)。《方案_详细版》中 [0,0.5]×[0,1.6] 的写法为同一几何的转置，不采用。

- **当前范围**：固定力学网络参数、V_n 场算一次后固定、α 固定 1.0、单次 HJB 演化不迭代（§2）。
- **采样与训练超参数**（N_r/N_0/N_b、Adam 步数）：暂取自《方案_详细版》并按下限调整，《实验设置与计算范围》尚未覆盖演化阶段；实现定稿后应回填《实验设置与计算范围》并同步本文档。
- **力学网络结构**：4×64 tanh（与《应力位移初始化说明》一致，本阶段冻结）；SDF 网络 3×64 tanh 不变。
- **孔洞边界**：ersatz 材料（E_void = 1e-6）自动满足 σ·n = 0，无需显式识别孔洞边界；Neumann 边界损失只涉及设计域外边界。

### 2026-09-08 方法修订（移除 L_b、IC 边界带、制造解锚点）

经网格对照版（`hjb_fem.py`，同一 V_n、同一初值的 Godunov 迎风参考解）对拍确认：

- **移除外边界损失 L_b**（原 §7 (3)）：参考论文对 SDF 不施加域边界条件；
  L_b 与 L_0 在 t=0 棱线冲突；且零 Neumann 条件下边界值被钉死（网格版实测
  φ_t = 0），零水平集永远无法从域边界后退。移除后边界为出流式，可自由后退。
- **rim 虚增的真正主因是初始条件锚定不足**（不是 L_b）：HJB 残差存在平解退化
  （常函数残差为零，只约束 φ_t/|∇φ| = V_n），φ 值完全靠 L_0 钉；纯内部 Sobol
  采样下 rim（零测集）无点，光滑网络把边界拐角抹圆，实测 rim 处 φ(t=0) 漂移
  +0.077（S→1，面积虚增 +0.028，与 L_b 移除与否无关）。修复：L_0 增加边界带
  加密点（带宽 4β、隔点严格压边、权重 w_ic = 10，同《SDF初始化说明》策略），
  rim 漂移降至 +0.01 量级。
- **新增制造解锚点 L_anchor**（§7 (3)，λ_anchor = 1，可置 0 关闭）：锚定 φ 到
  一阶制造解 φ_current + (t−t_current)·V_n·|∇φ_current|，给出整个时间柱面上的
  显式剖面目标，从根上破除平解退化。
- **网格对照版边界 stencil 同步改为内部单侧差分**（出流式，与 L_b 移除一致）。
- **注意**：制造解锚点为本次新增，尚未经完整训练验证（代码静态审查通过；
  验证运行待执行）。
