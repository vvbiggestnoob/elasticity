# 网络初始化说明

> **文档维护**：本文档是网络结构的唯一权威说明。实现代码必须与本文档保持一致；
> **实现完成后需要保存并更新本文档**，后续任何对网络结构的修改都要同步修订本文档。

---

## 1. 总体结构

共 **6 个神经网络**，分两组：

| 网络 | 输入 | 输出 | 作用 |
|------|------|------|------|
| `u_x` | (x, y) | 标量 | 位移 x 分量 |
| `u_y` | (x, y) | 标量 | 位移 y 分量 |
| `sigma_xx` | (x, y) | 标量 | 应力 σ_xx |
| `sigma_xy` | (x, y) | 标量 | 应力 σ_xy |
| `sigma_yy` | (x, y) | 标量 | 应力 σ_yy |
| `phi` | (x, y, **t**) | 标量 | 符号距离函数（SDF），含伪时间维 |

力学网络只依赖空间坐标 (x, y)；SDF 网络多一个伪时间维 t（用于后续 HJB 演化，初始化阶段恒取 t=0）。

## 2. 为什么用 5 个力学网络（混合格式）

直接用一个位移网络 + 二阶自动微分求 div σ 需要二阶导，代价高且噪声大。混合格式把位移和应力分开表示：

- 动量方程只涉及 **σ 网络的一阶导**（div σ）；
- 本构残差把 σ 网络绑定到 u 网络的应变（u 的一阶导）；
- 全程**只用一阶自动微分**，避免二阶导。

位移与应力的自洽性由本构残差损失强制（见《应力位移初始化说明》）。

## 3. 每个网络的结构

全连接 MLP：

- 隐藏层：**3 层 × 64 神经元**；
- 激活函数：**tanh**（光滑、适合 PINN 的自动微分）；
- 输出层：线性，1 维标量；
- 权重初始化：**Xavier 正态**初始化，偏置置 0。

参数量（以 3×64 为例）：

| 网络 | 输入维 | 参数量（约） |
|------|--------|--------------|
| 力学网络 | 2 | ~8.5 K |
| SDF 网络 | 3 | ~8.6 K |

> **实现实测**（2026-09-02，`start/networks.py`）：力学网络精确为 **8577**，SDF 网络精确为 **8641**。

## 4. 输入归一化（关键）

物理坐标 (x, y) 的量级差异大（x∈[0,1.6]，y∈[0,0.5]），直接喂给 tanh 网络会导致饱和、训练困难。因此在**网络第一层内置一个固定的仿射映射**（不可训练）：

$$
\tilde{x} = \frac{2x}{L_x} - 1, \qquad \tilde{y} = \frac{2y}{L_y} - 1
$$

把 (x, y) 归一化到 [-1, 1]²。SDF 网络的 t 通道**不归一化**（初始化恒为 0，演化阶段量级小）。

要点：

- 归一化写在前向传播内部，**对外接口始终是物理坐标**；
- 因为对输入求导时链式法则自动穿过这层固定仿射，**自动微分得到的仍是对物理坐标的导数**，损失公式无需改写。

## 5. 数值精度

全程使用 **float64**（双精度）。原因：L-BFGS 的强 Wolfe 线搜索在 float32 下容易因梯度/步长低于精度阈值而提前停滞，双精度是收敛到下界的前提。

## 6. 设计决策记录

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 激活函数 | tanh | 光滑，自动微分友好 |
| 隐藏层 | 3×64 | 表达力与 CPU 训练成本的平衡 |
| 输入归一化 | 内置固定仿射 | 避免 tanh 饱和，损失公式不变 |
| 权重初始化 | Xavier 正态 | 配合 tanh 的常用选择 |
| 精度 | float64 | L-BFGS 线搜索需要 |

## 7. 实现记录（2026-09-02）

实现代码位于 `start/`，使用文档位于 `start_files/使用文档.md`：

| 文件 | 内容 |
|------|------|
| `start/networks.py` | 核心实现：`NormalizedMLP`（内置固定归一化的 3×64 tanh MLP）、`build_mechanics_networks` / `build_sdf_network` / `build_all_networks`、`save_networks` / `load_networks` |
| `start/verify_networks.py` | 自检脚本，逐条验证本说明的规格（9 项全部通过） |
| `start/example_usage.py` | 最小使用示例 |

实现要点（与本说明各节的对应）：

- 归一化参数 `shift`/`scale` 注册为 `persistent=True` 的 buffer：不可训练，但随
  `state_dict` 保存，加载权重时归一化定义与训练时严格一致（§4）；
- Xavier 初始化在 float64 默认精度下直接进行，避免 float32 初始化再转换的精度损失（§3、§5）；
- 保存文件名为 `<名字>_init.pt`（`u_x_init.pt … phi_init.pt`），与《SDF初始化说明》
  《应力位移初始化说明》约定的文件名一致；
- 自检确认自动微分给出的是对物理坐标的导数（与中心差分对比，误差 ~2e-11）（§4）。

已知特性（非 bug）：偏置全零 + tanh 为奇函数，域中心点 (Lx/2, Ly/2) 处所有网络
输出恰为 0；训练开始后偏置更新，该对称性即消失。
