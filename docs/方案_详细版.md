# 基于 PINN-HJB 的特征值拓扑优化详细方案

---

## 一、问题定义

### 1.1 几何与材料设置

- **设计域**：$\Omega = [0, 0.5] \times [0, 1.6]$（宽 × 高）
- **固定重块**：中心区域 $[0.16, 0.24] \times [0.76, 0.84]$，密度 $\hat{\rho} = 100$
- **其他区域**：材料密度 $\hat{\rho} = 1$
- **孔洞区域**：密度 $\rho = 0$
- **体积约束**：目标面积 = $0.5 \times 1.6 \times 0.5 = 0.4$（即体积分数 50%）

### 1.2 弹性特征值方程

$$\nabla \cdot \boldsymbol{\sigma} = -\omega^2 \rho\, \boldsymbol{u}$$

展开为分量形式：

$$\begin{cases}
\dfrac{\partial \sigma_{xx}}{\partial x} + \dfrac{\partial \sigma_{xy}}{\partial y} = -\omega^2 \rho\, u_x \\[10pt]
\dfrac{\partial \sigma_{xy}}{\partial x} + \dfrac{\partial \sigma_{yy}}{\partial y} = -\omega^2 \rho\, u_y
\end{cases}$$

### 1.3 边界条件

| 边界 | 类型 | 条件 |
|------|------|------|
| 左端 ($x=0$) | Dirichlet | $u_x = 0,\; u_y = 0$ |
| 右端 ($x=0.5$) | Dirichlet | $u_x = 0,\; u_y = 0$ |
| 顶部 ($y=1.6$) | Neumann | $\sigma_{xy} = 0,\; \sigma_{yy} = 0$ |
| 底部 ($y=0$) | Neumann | $\sigma_{xy} = 0,\; \sigma_{yy} = 0$ |
| 孔洞边界 | Neumann | $\boldsymbol{\sigma} \cdot \boldsymbol{n} = 0$ |

### 1.4 优化目标

$$\min\; F = -\omega^2 + \frac{1}{2\alpha}\left(\int_\Omega S\, dx - C\right)^2$$

其中：
- $\omega^2$：最小特征值（取负号表示最大化）
- $S = H(\phi)$：Heaviside 函数，$\phi > 0$ 时 $S = 1$（有材料）
- $\rho = S \cdot \hat{\rho}$：实际密度
- $C = 0.4$：目标面积
- $\alpha$：罚参数（自适应更新）

## 二、网络架构

### 2.1 力学网络（5 个独立网络）

| 网络 | 输出 | 输入 | 架构 |
|------|------|------|------|
| $N_{u_x}$ | $u_x(x, y)$ | $(x, y)$ | 3 隐藏层 × 64 神经元 |
| $N_{u_y}$ | $u_y(x, y)$ | $(x, y)$ | 3 隐藏层 × 64 神经元 |
| $N_{\sigma_{xx}}$ | $\sigma_{xx}(x, y)$ | $(x, y)$ | 3 隐藏层 × 64 神经元 |
| $N_{\sigma_{xy}}$ | $\sigma_{xy}(x, y)$ | $(x, y)$ | 3 隐藏层 × 64 神经元 |
| $N_{\sigma_{yy}}$ | $\sigma_{yy}(x, y)$ | $(x, y)$ | 3 隐藏层 × 64 神经元 |

**激活函数**：tanh（保证光滑性和高阶导数存在）

### 2.2 SDF 网络（1 个网络）

| 网络 | 输出 | 输入 | 架构 |
|------|------|------|------|
| $N_{\phi}$ | $\phi(x, y, t)$ | $(x, y, t)$ | 3 隐藏层 × 64 神经元 |

**激活函数**：tanh

**说明**：SDF 网络的输入包含伪时间 $t$，用于 HJB 演化。

## 三、Heaviside 函数定义

由于标准 Heaviside 函数不可微，采用 **tanh 光滑近似**：

$$H(\phi) = \frac{1}{2}\left(1 + \tanh\left(\frac{\phi}{2\beta}\right)\right)$$

**参数选择**：
- $\beta = 0.01$（控制过渡带宽度，约为网格尺寸的 1~2 倍）

**梯度性质**：

$$H'(\phi) = \frac{1}{4\beta}\left(1 - \tanh^2\left(\frac{\phi}{2\beta}\right)\right)$$

- 梯度**处处非零**（虽然 $|\phi|$ 大时指数级小），PINN 训练更稳定
- 无限光滑（$C^\infty$），适合自动微分
- 实现简单，一行代码

**材料分布**：

$$S = H(\phi), \qquad \rho = S \cdot \hat{\rho}$$

**弹性模量**：

$$E = S \cdot E_{solid} + (1 - S) \cdot E_{void}$$

其中 $E_{solid} = 1$，$E_{void} = 10^{-6}$（避免刚度矩阵奇异）。

> **为什么不使用分段函数？** 分段 Heaviside 在 $|\phi| > \Delta$ 时梯度严格为零，导致 SDF 网络在远离边界的区域接收不到梯度信号，影响 PINN 训练稳定性。tanh 版本梯度处处非零，更适合神经网络训练。

## 四、初始化阶段

### 4.1 SDF 网络预训练

**目标**：让 SDF 网络拟合初始形状 $\Phi_0$

**初始形状**：**全材料**（无孔洞），SDF 为到设计域边界的距离：

$$\Phi_0(x, y) = \min(x,\; 0.5 - x,\; y,\; 1.6 - y)$$

在设计域内处处为正，零水平集即为设计域边界。

**优点**：
- 解析表达式简单，SDF 网络容易拟合
- 不需要预训练很久
- 优化过程中孔洞自然生成

**损失函数**：

$$L_{init} = \frac{1}{N_{init}}\sum_{i=1}^{N_{init}} \left| N_\phi(x_i, y_i, 0) - \Phi_0(x_i, y_i) \right|^2$$

**训练细节**：

| 参数 | 值 |
|------|-----|
| 优化器 | Adam |
| 学习率 | $10^{-3}$ |
| 迭代步数 | 1000~2000（初始形状简单，容易拟合） |
| 采样点数 $N_{init}$ | 5000 |

**终止条件**：$L_{init} < 10^{-6}$

### 5.2 Step A：力学方程训练

#### 5.2.1 计算材料分布

$$\phi = N_\phi(x, y, t_{current})$$

$$S = H_\delta(\phi)$$

$$\rho = S \cdot \hat{\rho}$$

#### 5.2.2 通过 FEM 获取参考特征值 $\hat{\omega}^2$

用当前材料分布 $\rho$ 进行 FEM 特征值分析，得到参考特征值 $\hat{\omega}^2$。

**注意**：FEM 计算时需要考虑 $S$，即在孔洞区域（$S \approx 0$）使用极小的弹性模量 $E_{void} = 10^{-6}$，避免刚度矩阵奇异。

#### 5.2.3 构建 PINN 损失函数

总损失函数：

$$L_{mech} = \lambda_{eq} L_{eq} + \lambda_{const} L_{const} + \lambda_{D} L_{D} + \lambda_{N} L_{N} + \lambda_{eig} L_{eig}$$

---

##### (1) 平衡方程损失 $L_{eq}$

$$\frac{\partial \sigma_{xx}}{\partial x} + \frac{\partial \sigma_{xy}}{\partial y} = -\omega^2 \rho\, u_x$$

$$\frac{\partial \sigma_{xy}}{\partial x} + \frac{\partial \sigma_{yy}}{\partial y} = -\omega^2 \rho\, u_y$$

**注意**：在孔洞区域（$S \approx 0$），$\rho \approx 0$，右端项趋近于 0。为了过滤孔洞的影响，损失函数乘以 $S$：

$$L_{eq} = \frac{1}{N_r}\sum_{i=1}^{N_r} S_i \left[ \left( \frac{\partial \sigma_{xx}}{\partial x} + \frac{\partial \sigma_{xy}}{\partial y} + \omega^2 \rho\, u_x \right)^2 + \left( \frac{\partial \sigma_{xy}}{\partial x} + \frac{\partial \sigma_{yy}}{\partial y} + \omega^2 \rho\, u_y \right)^2 \right]_{x=x_i}$$

其中偏导数通过自动微分计算：

```python
sigma_xx = N_sigma_xx(x, y)
sigma_xy = N_sigma_xy(x, y)
sigma_yy = N_sigma_yy(x, y)

dsigma_xx_dx = torch.autograd.grad(sigma_xx, x, create_graph=True)[0]
dsigma_xy_dy = torch.autograd.grad(sigma_xy, y, create_graph=True)[0]
# ...
```

---

##### (2) 本构方程损失 $L_{const}$

平面应力本构关系：

$$\sigma_{xx} = \frac{E}{1-\nu^2}\left( \varepsilon_{xx} + \nu\, \varepsilon_{yy} \right)$$

$$\sigma_{yy} = \frac{E}{1-\nu^2}\left( \varepsilon_{yy} + \nu\, \varepsilon_{xx} \right)$$

$$\sigma_{xy} = \frac{E}{2(1+\nu)}\, \varepsilon_{xy}$$

其中应变-位移关系：

$$\varepsilon_{xx} = \frac{\partial u_x}{\partial x}, \quad \varepsilon_{yy} = \frac{\partial u_y}{\partial y}, \quad \varepsilon_{xy} = \frac{\partial u_x}{\partial y} + \frac{\partial u_y}{\partial x}$$

**材料参数**：
- $E = 1$（固体），$E = 10^{-6}$（孔洞）
- $\nu = 0.3$

损失函数（乘以 $S$ 过滤孔洞）：

$$L_{const} = \frac{1}{N_r}\sum_{i=1}^{N_r} S_i \left[ \left( \sigma_{xx} - \frac{E}{1-\nu^2}(\varepsilon_{xx} + \nu\varepsilon_{yy}) \right)^2 + \left( \sigma_{yy} - \frac{E}{1-\nu^2}(\varepsilon_{yy} + \nu\varepsilon_{xx}) \right)^2 + \left( \sigma_{xy} - \frac{E}{2(1+\nu)}\varepsilon_{xy} \right)^2 \right]_{x=x_i}$$

---

##### (3) Dirichlet 边界损失 $L_D$

在左端 ($x=0$) 和右端 ($x=0.5$)：

$$L_D = \frac{1}{N_D}\sum_{i=1}^{N_D} \left[ u_x^2 + u_y^2 \right]_{x \in \Gamma_D}$$

采样方式：在 $x=0$ 和 $x=0.5$ 的边界上均匀采样 $N_D = 100$ 个点。

---

##### (4) Neumann 边界损失 $L_N$

**只需要考虑设计域的外边界**（顶部和底部），孔洞边界通过 ersatz material 方法自动满足。

对于顶部 ($y=1.6$) 和底部 ($y=0$)，法向 $\boldsymbol{n} = (0, \pm 1)$：

$$\sigma_{xy} = 0, \quad \sigma_{yy} = 0$$

损失函数：

$$L_N = \frac{1}{N_N}\sum_{i=1}^{N_N} \left[ \sigma_{xy}^2 + \sigma_{yy}^2 \right]_{y=0 \text{ or } y=1.6}$$

> **孔洞边界为何不施加 Neumann 条件？** 采用 ersatz material 方法：孔洞区域使用极小弹性模量 $E_{void} = 10^{-6}$，孔洞区域的应力自然趋近于零，自动近似满足 $\sigma \cdot n = 0$。这是水平集拓扑优化的标准做法，无需显式识别孔洞边界。

---

##### (5) 特征值损失 $L_{eig}$

Rayleigh 商：

$$R = \frac{\displaystyle\int_\Omega S \cdot \boldsymbol{\varepsilon}(\boldsymbol{u}) : \boldsymbol{C} : \boldsymbol{\varepsilon}(\boldsymbol{u})\, d\Omega}{\displaystyle\int_\Omega S \cdot \hat{\rho}\, |\boldsymbol{u}|^2\, d\Omega}$$

**注意**：分子分母都乘以 $S$ 过滤孔洞。

特征值损失：

$$L_{eig} = \left( \frac{R}{\hat{\omega}^2} - 1 \right)^2$$

其中 $\hat{\omega}^2$ 是 FEM 计算的参考特征值。

**数值积分**：在域内采样 $N_{int} = 2000$ 个点，用蒙特卡洛方法近似积分：

$$R \approx \frac{\displaystyle\frac{1}{N_{int}}\sum_{i=1}^{N_{int}} S_i \cdot \boldsymbol{\varepsilon}_i : \boldsymbol{C} : \boldsymbol{\varepsilon}_i}{\displaystyle\frac{1}{N_{int}}\sum_{i=1}^{N_{int}} S_i \cdot \hat{\rho}_i \cdot |\boldsymbol{u}_i|^2}$$

---

### 5.3 Step B：SDF 演化（HJB 方程）

#### 5.3.1 灵敏度分析 → 计算 $V_n$

从 Step A 得到位移场 $\boldsymbol{u}$、应变场 $\boldsymbol{\varepsilon}$、应力场 $\boldsymbol{\sigma}$ 和特征值 $\omega^2$。

**法向速度**：

$$V_n = \underbrace{\boldsymbol{\varepsilon}(\boldsymbol{u}) : \boldsymbol{C} : \boldsymbol{\varepsilon}(\boldsymbol{u})}_{\text{应变能密度}} - \omega^2 \underbrace{\rho\, |\boldsymbol{u}|^2}_{\text{动能密度}} - \frac{1}{\alpha}\left( \int_\Omega S\, dx - C \right)$$

**物理含义**：
- 应变能密度大 → 材料对刚度贡献大 → $V_n > 0$ → 边界向外扩张
- 动能密度大 → 材料对质量贡献大 → 降低特征值 → $V_n < 0$ → 边界收缩
- 罚项：当前面积偏大时，$V_n$ 减小 → 收缩

#### 5.3.2 HJB 方程

$$\frac{\partial \phi}{\partial t} + V_n |\nabla \phi| = 0$$

#### 5.3.3 PINN 损失函数

$$L_{HJB} = \lambda_r L_r + \lambda_0 L_0 + \lambda_b L_b$$

---

##### (1) HJB 残差损失 $L_r$

$$L_r = \frac{1}{N_r}\sum_{i=1}^{N_r} \left| \frac{\partial \tilde{\phi}}{\partial t}(x_i, y_i, t) + V_n(x_i, y_i) \cdot |\nabla \tilde{\phi}(x_i, y_i, t)| \right|^2$$

其中：
- $\tilde{\phi}(x, y, t) = N_\phi(x, y, t; \theta)$
- $\frac{\partial \tilde{\phi}}{\partial t}$ 通过自动微分计算
- $|\nabla \tilde{\phi}| = \sqrt{\left(\frac{\partial \tilde{\phi}}{\partial x}\right)^2 + \left(\frac{\partial \tilde{\phi}}{\partial y}\right)^2}$

> **注意**：HJB 损失**不乘以 $S$**。SDF 需要在整个设计域上演化，如果过滤孔洞区域，SDF 在孔洞区域不更新，就无法生成新孔洞或扩大现有孔洞。$V_n$ 在孔洞区域自然趋近于罚项（前两项因 $E \approx 0$ 和 $\rho \approx 0$ 而消失），无需额外过滤。

---

##### (2) 初始条件损失 $L_0$

在 $t = t_{current}$ 时刻，SDF 应该等于当前 SDF：

$$L_0 = \frac{1}{N_0}\sum_{i=1}^{N_0} \left| \tilde{\phi}(x_i, y_i, t_{current}) - \phi_{current}(x_i, y_i) \right|^2$$

---

##### (3) 边界条件损失 $L_b$

在设计域边界上，SDF 的值不应剧烈变化（零法向梯度）：

$$L_b = \frac{1}{N_b}\sum_{i=1}^{N_b} \left| \frac{\partial \tilde{\phi}}{\partial \boldsymbol{n}}(x_i, y_i, t) \right|^2$$

---

### 5.4 Step C：重初始化

#### 5.4.1 重初始化方程

$$\frac{\partial \phi}{\partial \tau} = \text{sign}(\phi_0)(1 - |\nabla \phi|)$$

其中 $\phi_0$ 是当前 SDF（重初始化前的状态）。

#### 5.4.2 PINN 损失函数

$$L_{reinit} = \lambda_{eik} L_{eik} + \lambda_{pos} L_{pos}$$

---

##### (1) Eikonal 约束损失 $L_{eik}$

$$L_{eik} = \frac{1}{N_r}\sum_{i=1}^{N_r} \left| |\nabla \tilde{\phi}(x_i, y_i)| - 1 \right|^2$$

---

##### (2) 位置保持损失 $L_{pos}$

保持零水平集位置不变：

$$L_{pos} = \frac{1}{N_0}\sum_{i=1}^{N_0} \left| \tilde{\phi}(x_i, y_i) - \phi_0(x_i, y_i) \right|^2$$

**采样策略**：在当前零水平集附近（$|\phi_0| < 0.1$）密集采样。

---

#### 5.4.3 训练细节

| 参数 | 值 | 说明 |
|------|-----|------|
| 优化器 | Adam | |
| 学习率 | $10^{-4}$ | 比 HJB 小，避免剧烈变化 |
| 训练步数 | 50~100 步 | 不要过度训练 |
| 重初始化频率 | 每 5~10 步 HJB | 减少累积漂移 |
| $\lambda_{eik}$ | 1 | |
| $\lambda_{pos}$ | 10 | 强调位置保持 |

#### 5.4.4 终止条件

- Eikonal 残差 < $10^{-2}$（在零水平集附近监测）
- 或达到最大步数（100 步）

### 5.5 Step D：更新罚参数

$$\frac{1}{\alpha^{(k+1)}} = \min\left( \frac{\omega^2 \cdot \tau}{\left( \int_\Omega S\, dx - C \right)^2},\; \alpha_{max} \right)$$

**参数**：
- $\tau = 1.1$（缩放因子）
- $\alpha_{max} = 10^{6}$（罚参数上限）

**物理含义**：
- 面积偏差大 → $1/\alpha$ 受限于 $\alpha_{max}$ → 罚项强 → 优先满足面积约束
- 面积接近目标 → $1/\alpha$ 由 $\omega^2 \tau / (\Delta V)^2$ 控制 → 罚项适中 → 更关注特征值优化

## 六、注意事项

### 6.1 孔洞过滤

**力学相关损失**需要乘以 $S$ 过滤孔洞区域：

- **平衡方程**：$L_{eq}$ 中乘以 $S$
- **本构方程**：$L_{const}$ 中乘以 $S$
- **Rayleigh 商**：分子分母都乘以 $S$
- **FEM 计算**：孔洞区域使用 $E = 10^{-6}$

**SDF 相关损失**不需要乘以 $S$：

- **HJB 演化**：$L_{HJB}$ 不乘 $S$，SDF 需要在整个域上演化
- **重初始化**：$L_{reinit}$ 不乘 $S$，SDF 性质需要在整个域上保持

### 6.2 孔洞边界处理

采用 **ersatz material** 方法，无需显式识别孔洞边界：

- 孔洞区域使用极小弹性模量 $E_{void} = 10^{-6}$
- 孔洞区域应力自然趋近于零，自动近似满足 $\sigma \cdot n = 0$
- Neumann 边界损失只需考虑设计域外边界（顶部和底部）

### 6.3 面积约束

目标面积 = $0.5 \times 1.6 \times 0.5 = 0.4$

体积分数 = $\dfrac{\int_\Omega S\, dx}{0.5 \times 1.6} = 0.5$

### 6.4 最终输出

最终图像输出时，位移、应力、应变都要乘以 $S$，让孔洞区域为 0：

$$u_{final} = S \cdot u, \quad \sigma_{final} = S \cdot \sigma, \quad \varepsilon_{final} = S \cdot \varepsilon$$

### 6.5 数值稳定性

- 使用 tanh 激活函数（光滑、高阶导数存在）
- Heaviside 函数使用 tanh 版本，梯度处处非零
- 重初始化学习率小于 HJB 学习率
- 监测 Eikonal 残差，避免过度训练
- FEM 计算时孔洞区域使用极小弹性模量，避免刚度矩阵奇异

## 七、收敛判据

满足以下条件之一时停止外层循环：

1. **目标函数变化**：$|F^{(k+1)} - F^{(k)}| / |F^{(k)}| < 10^{-4}$
2. **SDF 变化**：$\|\phi^{(k+1)} - \phi^{(k)}\|_\infty < 10^{-3}$
3. **最大迭代步数**：$k > 200$

## 八、伪代码

```python
# ========== 初始化 ==========
# 网络定义
u_x_net = Network(input_dim=2, output_dim=1, hidden=[64, 64, 64])
u_y_net = Network(input_dim=2, output_dim=1, hidden=[64, 64, 64])
sigma_xx_net = Network(input_dim=2, output_dim=1, hidden=[64, 64, 64])
sigma_xy_net = Network(input_dim=2, output_dim=1, hidden=[64, 64, 64])
sigma_yy_net = Network(input_dim=2, output_dim=1, hidden=[64, 64, 64])
phi_net = Network(input_dim=3, output_dim=1, hidden=[64, 64, 64])  # 输入 (x, y, t)

# Heaviside 函数（tanh 版本）
def heaviside(phi, beta=0.01):
    return 0.5 * (1 + torch.tanh(phi / (2 * beta)))

# SDF 预训练（全材料初始化）
phi_0 = lambda x, y: torch.min(torch.stack([x, 0.5-x, y, 1.6-y]), dim=0)  # 到边界的距离
train_sdf_initialization(phi_net, phi_0, steps=2000)

# 罚参数初始化
alpha = 1.0
alpha_max = 1e6
tau = 1.1
C = 0.4  # 目标面积

# ========== 外层循环 ==========
for outer_iter in range(max_outer_iter):
    
    # ----- Step A: 力学方程训练 -----
    # 计算材料分布
    phi_current = phi_net(x, y, t_current)
    S = heaviside(phi_current)
    rho = S * rho_hat
    E = S * E_solid + (1 - S) * E_void  # E_void = 1e-6
    
    # FEM 获取参考特征值
    omega_hat_sq = fem_eigenvalue(rho)
    
    # PINN 训练（力学损失乘 S 过滤孔洞）
    for step in range(mech_steps):
        loss = (lambda_eq * equilibrium_loss() * S      # 乘 S
                + lambda_const * constitutive_loss() * S  # 乘 S
                + lambda_D * dirichlet_loss()             # 外边界
                + lambda_N * neumann_loss()               # 仅外边界
                + lambda_eig * eigenvalue_loss(omega_hat_sq))  # 乘 S
        loss.backward()
        optimizer_mech.step()
    
    # 计算当前特征值和位移场
    omega_sq = compute_rayleigh_quotient()  # 乘 S
    u = (u_x_net(x, y), u_y_net(x, y))
    
    # ----- Step B: SDF 演化 -----
    # 灵敏度分析
    V_n = compute_sensitivity(omega_sq, u, rho, alpha, C)
    
    # HJB 训练（不乘 S，SDF 需要在整个域上演化）
    for hjb_step in range(hjb_steps):
        loss_hjb = (lambda_r * hjb_residual_loss(V_n)      # 不乘 S
                    + lambda_0 * initial_condition_loss()
                    + lambda_b * boundary_condition_loss())
        loss_hjb.backward()
        optimizer_hjb.step()
        
        # ----- Step C: 重初始化 -----
        if hjb_step % reinit_freq == 0:
            phi_0 = phi_net(x, y, t_current).detach()
            for reinit_step in range(reinit_steps):
                loss_reinit = (lambda_eik * eikonal_loss()      # 不乘 S
                               + lambda_pos * position_loss(phi_0))
                loss_reinit.backward()
                optimizer_reinit.step()
    
    # ----- Step D: 更新罚参数 -----
    volume = compute_volume(S)
    alpha = update_alpha(omega_sq, volume, C, alpha_max, tau)
    
    # 检查收敛
    if converged():
        break
```
