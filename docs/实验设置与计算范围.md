# 实验设置与计算范围说明

> **文档维护**：本文档记录当前实验的计算范围与全部具体数值，是实现的核对依据。
> **实现完成后需要保存并更新本文档**；任何参数改动都要同步修订本文档。

---

## 1. 物理问题

在面积约束下求使**最小弹性特征值最大**的最优拓扑（特征值拓扑优化）：

$$
\max_{\text{拓扑}}\ \omega_1^2, \qquad \text{s.t.}\quad \int_\Omega S\,d\Omega = V_{\text{target}}
$$

其中弹性特征值方程（时谐约定）：

$$
-\nabla\!\cdot\!\boldsymbol{\sigma} = \omega^2 \rho\,\mathbf{u}
$$

材料由符号距离函数（SDF）经 Heaviside 表示：$\ S = H(\phi)$，$\ \rho = S\,\hat\rho$。

## 2. 当前实验的计算范围

**范围内（当前阶段 = 初始化 + 单次 SDF 优化）**：
1. 网络搭建（6 个网络，见《网络初始化说明》）；
2. SDF 初始化：t=0 切片拟合全材料距离函数（见《SDF初始化说明》）；
3. 应力/位移初始化：全材料几何上的 PINN 特征值训练，FEM 给锚点（见《应力位移初始化说明》）；
4. 单次 SDF 优化：冻结力学网络参数，当前几何上算一次 V_n，做一次 HJB 演化（Adam → L-BFGS 两阶段，推进一个 dt），不进入外层迭代（见《HJB方程优化说明》《重初始化方案说明》）。

**范围外（后续阶段，本文档不覆盖）**：
- 交替迭代的主循环（拓扑优化本体）；
- 罚参数 α 的自适应更新（单次阶段 α 固定为 1.0）；
- 多步 HJB 演化中的周期性重初始化（单次演化默认不触发）。

## 6. 边界条件

| 边界 | 条件 | 类型 |
|------|------|------|
| 左 x=0 | u_x = u_y = 0 | Dirichlet（固支） |
| 右 x=Lx | u_x = u_y = 0 | Dirichlet（固支） |
| 下 y=0 | σ_xy = σ_yy = 0 | Neumann（自由） |
| 上 y=Ly | σ_xy = σ_yy = 0 | Neumann（自由） |
| 孔洞边界 | σ·n = 0 | 自由（由 ersatz/掩码自动满足） |

## 7. SDF / Heaviside 参数

| 量 | 数值 | 说明 |
|----|------|------|
| β | 0.01 | Heaviside 过渡参数，S=½(1+tanh(φ/2β)) |
| 敏感带 | \|φ\| ≲ 4β ≈ 0.04 | S 对 φ 误差敏感的范围 |
| 初始 φ₀ | min(x, Lx−x, y, Ly−y) | 全材料距离函数 |
| offset | 0 | 零水平集压在域边界上（边界 S=0.5） |
| dt | 0.005 | SDF 伪时间步长（演化阶段用） |

## 10. 网络规模

| 网络 | 输入 | 结构 | 参数量 |
|------|------|------|--------|
| 5 个力学网络 | (x, y) | 4×64 tanh | ~12.7 K each |
| 1 个 SDF 网络 | (x, y, t) | 3×64 tanh | ~8.6 K |

> 力学网络 2026-09 起由 3×64 加深为 4×64（`MechInitConfig.hidden_layers`），
> 加深后旧权重不兼容、需重新训练；SDF 网络保持 3×64（其已训练权重与结构绑定）。

输入坐标内置归一化到 [-1,1]²；全程 float64。
